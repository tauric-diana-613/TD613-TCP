## Operational contract

Atlas consumes an admitted Holonomy Loom semantic field and builds a versioned Portable-AIA Flow-Core control envelope containing:

- source revision and scene identity;
- Flow-Core phase;
- relation keys;
- the exact glyph trace;
- a legend mapping each glyph to its semantic relation, motion grammar, static equivalent, inspection grammar, and authority ceiling;
- governance state;
- V/C/P/L evidentiary coordinates;
- route state, missingness, and contradictions;
- claim ceilings;
- an explicit return rule.

The child and auditor projections may look different. The machine control plane must remain equal.

```text
SAME_CONTROL_PLANE != SAME_PRESENTATION
SAME_RELATION != SAME_RECEIVER_INFORMATION
SAME_GLYPH_TRACE != SUFFICIENT_RETURN_RECEIPT
REMOTE_HOST_OPERATION != AUTHORITY_TRANSFER
RETURN_TO_TD613 != TRUST_TRANSFER
```

A bare glyph string is intentionally insufficient. It must travel with its versioned legend and governance state before Atlas treats it as an auditable Flow-Core trace.

## Declared continuity-difference adapter

`app/engine/dollhouse-continuity-audit.js::runAtlasContinuityAudit` adds a pure,
bounded comparison without changing the installed `runAtlasAgent` interface.

Its input declares `origin`, `previous`, `current`, and optional receiver
`presentations`. Each snapshot has an `id` and these coordinates:

| Coordinate | Meaning |
| --- | --- |
| `source_revision` | Declared source revision; never source authentication |
| `original_ref` | Reference for the original result/root |
| `current_ref` | Reference for the result presented as current in this snapshot |
| `predecessor_ref` | Declared immediate parent, or explicit `null` for the root |
| `selected_commitments` | Declared `{id, commitment}` pairs; no source contents |
| `policy_commitment` | Declared rules/control commitment |
| `missingness` | Advisory missingness declarations |
| `claim_ceiling` | Declared claim bounds preserved exactly as a set |

The origin must declare `current_ref == original_ref` with a null predecessor.
Missing coordinates produce `UNKNOWN`; explicit
`{withheld: true, reason: "..."}` produces `WITHHELD`. These states remain
distinct from an explicitly declared empty set. Both hold the comparison.
Malformed declarations, sparse arrays, duplicate selections and accessors are
rejected rather than normalized into apparently complete evidence.

The adapter reports `PRESERVED`, `CHANGED`, `UNKNOWN`, or `WITHHELD` for each
coordinate. Original root, revision, selected commitments, policy and claim
ceiling must remain invariant. Current-result references may evolve when the
declared immediate parent matches the previous current reference. Changed
missingness remains visible and advisory. Receiver controls are compared at
the same declared current state; presentation styling and prose are outside
the input and need not be equal.

The strongest positive verdict is `DECLARED_CONSISTENCY`. Caller-provided
commitments and matching references never become authenticated result
admission. Signature verification is outside this adapter. Even an externally
verified parent chain would require additional state/custody evidence to
establish global latest state or exclude forks and replay; those conclusions
remain explicitly unearned here.
