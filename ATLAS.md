# TD613 Atlas

This is the canonical repository shortcut into the bounded Atlas receiver-relation audit lane.

Atlas asks a narrow question:

> When one admitted relation is projected through intentionally non-equivalent receivers, what control state must remain invariant, what presentation may change, and what must be revalidated on return?

Atlas is operational here as a bounded research adapter. It does not silently import or merge the separately receipt-bound Atlas research estate.

## Run it

From repository root:

```bash
node scripts/run-dollhouse-agent-audit.mjs atlas
node scripts/run-dollhouse-agent-audit.mjs atlas 3
node tests/dollhouse-atlas-fadt.test.mjs
```

## Operational contract

Atlas consumes an admitted Holonomy Loom semantic field and builds a versioned Portable-AIA Flow-Core control envelope containing:

- source revision and scene identity;
- Flow-Core phase;
- relation keys;
- the exact glyph trace;
- a legend mapping each glyph to its semantic relation, motion grammar, static equivalent, inspection grammar, and authority ceiling;
- governance state;
- V/C/P/L evidentiary coordinates;
- route state, missingness, and contradictions;
- claim ceilings;
- an explicit return rule.

The child and auditor projections may look different. The machine control plane must remain equal.

```text
SAME_CONTROL_PLANE != SAME_PRESENTATION
SAME_RELATION != SAME_RECEIVER_INFORMATION
SAME_GLYPH_TRACE != SUFFICIENT_RETURN_RECEIPT
REMOTE_HOST_OPERATION != AUTHORITY_TRANSFER
RETURN_TO_TD613 != TRUST_TRANSFER
```

A bare glyph string is intentionally insufficient. It must travel with its versioned legend and governance state before Atlas treats it as an auditable Flow-Core trace.

## Portable return

A remote companion may return a bounded candidate, but arrival grants no trust. The return must preserve the declared control fields and come back through Loom revalidation before human use.

This makes a separate audit thread a lawful future realization: one thread may operate over the projected AIA state while another checks the returned control receipt against the origin relation and claim ceiling. The present adapter defines the control contract; it does not claim a live provider integration.

## Relation to phasonic supermoiré tomography

Phasonic supermoiré tomography remains an important research bridge for comparing what changes under receiver/projection variation against what remains conserved. Atlas can supply a clean finite control-plane witness for those comparisons.

That relationship does not promote this adapter into physical, continuum, basis-free, or empirical geometry. It is a bounded receiver-relation audit surface.

## Authority ceiling

Atlas does not grant:

- basis-free canonical geometry;
- physical tomography or physical holonomy;
- external-origin evidence;
- hidden-state access;
- provider authority;
- release authority;
- merge or deployment authority;
- Vercel authority;
- automatic promotion of the unmerged Atlas research lineage.

Human closure remains required.
