# TD613 Dollhouse

`Dollhouse/` is the human-findable shortcut house for TD613 thinking instruments and companion programs.

It is navigation, not a new authority layer.

```text
Dollhouse
├── Pedagogue · consequence, routes, practice, learning, rest, transfer
└── Aperture  · observability, identifiability, reconstruction, uncertainty, abstention
```

The house may gain another doll or toy only when that instrument has an earned repository identity and a reason to be found here. Being placed in Dollhouse does not transfer authority between instruments.

## Pedagogue

- Doll card: [`PEDAGOGUE.md`](PEDAGOGUE.md)
- Full repository contract: [`../PEDAGOGUE.md`](../PEDAGOGUE.md)
- Standalone Playhouse: [`../app/pedagogue/index.html`](../app/pedagogue/index.html)

Pedagogue proposes or reframes the human route. It preserves consequence-before-ontology, route memory, rest/exit, non-equivalent AIA projections, and human closure.

## Aperture

- Doll card: [`APERTURE.md`](APERTURE.md)
- Full repository contract: [`../APERTURE.md`](../APERTURE.md)
- Standalone instrument: [`../app/aperture/index.html`](../app/aperture/index.html)

Aperture audits what the admitted observation can distinguish, whether reconstruction is stable, and whether widening deserves `PROPOSE`, `ABSTAIN`, `REJECT`, or `ASK_NOTHING`.

## House law

```text
DOLLHOUSE_PLACEMENT != AUTHORITY_TRANSFER
FRIENDLY_SHORTCUT != ONTOLOGY_MERGE
PEDAGOGUE_PROPOSES != APERTURE_APPROVES
APERTURE_AUDITS != EXPERIMENT_EXECUTION
PLAYFUL_PRESENTATION != LOWERED_CLAIM_CEILING
```

Default relation when both dolls are needed:

```text
Pedagogue proposes or reframes
→ Aperture audits the admitted observation / reconstruction geometry
→ Dome-World hosts any warranted assay
→ Human closes
```

No Dollhouse object grants merge, deployment, release, production mutation, experiment execution, or autonomous redesign authority.
