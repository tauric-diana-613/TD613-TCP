## 3. Direction and word convention

A finite path word is a nonempty left-to-right execution list over `{T,Q}`.

Examples:

```text
[T,Q] means execute T, then execute Q
[Q,T] means execute Q, then execute T
[T,T,T,T] means four successive T generators
```

When translated into function notation:

```text
[T,Q] = Q ∘ T
[Q,T] = T ∘ Q
```

This convention must be recorded in every path receipt so prose ordering cannot silently invert mathematical ordering.

The bounded exhaustive word family for the primary witness is:

```text
all nonempty words over {T,Q} of lengths 1, 2, 3, and 4
```

There are exactly:

```text
2 + 4 + 8 + 16 = 30
```

such words.

No infinite path language, completion, free-category claim, or arbitrary-depth theorem is authorized.
