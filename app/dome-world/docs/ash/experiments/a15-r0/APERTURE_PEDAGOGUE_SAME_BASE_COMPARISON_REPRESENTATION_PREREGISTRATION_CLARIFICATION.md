## Correction

The original spec used the shorthand

```text
Im(rho_b)=2Z
```

for a base with block-distribution freedom.

That wording is too strong and is corrected **before implementation**.

For fixed `b=(t,E,O)`, the route set `R_b` is finite because every route has fixed total length `t+E+O`. Therefore the literal set

```text
D_b={P(u)-P(v):u,v in R_b}
```

is finite and cannot equal the infinite subgroup `2Z`.

The corrected all-finite theorem target is:

```text
D_b subseteq 2Z
```

and the subgroup of integer translations **generated by** the represented return automorphisms satisfies

```text
<rho_b(G_b)> = {id}
```

when no block-distribution freedom exists, while

```text
<rho_b(G_b)> = {tau_(2m):m in Z} ≅ 2Z
```

when block-distribution freedom exists.

Equivalently, for translation amounts:

```text
<D_b>_Z = {0} or 2Z.
```

The proof target remains finite and exact:

- parity forces every element of `D_b` to be even;
- freedom realizes `±2` as an actual represented return;
- the subgroup generated by that actual return therefore contains every even multiple;
- no-freedom bases have `D_b={0}`.

## Consequence for terminology

Use:

```text
represented finite return-difference set D_b
generated return-translation subgroup <D_b>
```

Do **not** call `2Z` the literal image set of a finite route family.

All other preregistered obligations remain unchanged.

No implementation, hostile result, witness, or theorem output preceded this correction.
