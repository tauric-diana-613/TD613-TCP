## 4. Pedagogue authoring consequences

Pedagogue second-pass verdicts:

1. **Keep Moss Lantern a research/calibration object.** No dedicated UI is justified by these papers.
2. **Do not collapse all recent science into one fixture.** Separate tests by epistemic job.
3. **Treat probe independence as a first-class control.** Multiple observations may be correlated.
4. **Make temporal order first-class.** Route history may not be reduced to a visited-state set.
5. **Give structured nonclosure a dynamic perturbation test.** Static φ anti-aliasing is insufficient.
6. **Preserve an aperiodic non-φ control.** Any φ-specific superiority must beat generic nonrepetition, not merely periodic repetition.
7. **Use transformed representations only under declared equivalence law.** Easier visibility is not new ontology.
8. **Keep inverse design downstream of reconstruction validation.** A target-to-realization loop must consume an epistemic constitution rather than silently expand the claim.
9. **Use held-out perturbations.** A fixture cannot certify generalization solely on the family that authored its detector.
10. **No deployment implication.** This research packet changes no production surface.

## 5. Immediate implementation decision

The next executable Moss Lantern pass should implement **ML1 + the minimum ML2 controls**, not ML3–ML7 simultaneously.

Reason:

- ML0 already demonstrates route-memory sensitivity;
- Wedding calibrated relational-vs-redundant/shuffled measurement logic;
- ML1 is the smallest test of the proprietary structured-nonclosure hypothesis;
- ML2 prevents any apparent ML1 gain from being misread as independent information when it is correlation/repetition;
- ML3 temporal order should follow on the same phantom after the reference-identifiability machinery is stable;
- transport/holonomy remains later.

The first implementation therefore asks only:

```text
Under matched observation budget, density, noise and decoder,
does the structured-nonclosure reference reduce ambiguity
relative to periodic repetition,
while a generic aperiodic control tests whether any gain is phi-specific?
```

If the generic aperiodic control equals or exceeds the quasiperiodic condition, the result must be reported as support for **nonrepetition/anti-aliasing**, not for φ-specific advantage.
