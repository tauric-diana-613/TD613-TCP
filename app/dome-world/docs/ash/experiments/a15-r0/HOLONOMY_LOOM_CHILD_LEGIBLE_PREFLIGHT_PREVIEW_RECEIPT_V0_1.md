- consequence before ontology;
- explicit human route/protection selection;

- no source-content transport authorization;

```text

```

`CHILD-LEGIBLE ACTION CLASS != COGNITIVE CLASSIFICATION`

## Deterministic policy layer

The current preview hard-blocks only bounded deterministic classes:

- private-key blocks;
- bearer-token-shaped credentials;
- a small declared family of common API-key shapes;
- exact user-declared protected phrases.

It emits bounded CHANGE warnings for:

- email addresses;
- phone numbers;
- exact RFC3339-like timestamps.

This family is intentionally incomplete.

`NO MATCH != NO SENSITIVE INFORMATION`

`GREEN != ZERO PRIVACY RISK`

`DETERMINISTIC POLICY FAMILY != UNIVERSAL DLP`

## Safer-copy boundary

The Loom-controlled copy action remains unavailable while the checked release candidate has a hard RED.

`makeHolonomyLoomSaferCopy(...)` replaces supported matched material, then reapplies the built-in deterministic policy family before declaring the generated candidate releasable through the Loom preview.

Generated replacement wording is not reclassified against arbitrary original exact user phrases, because every original exact occurrence was exhaustively removed before the recheck. A hostile test covers the replacement-collision case.

The resulting promise is bounded:

> **The Loom may control what it lets leave through its own release action. It cannot control every room the message enters afterward.**
