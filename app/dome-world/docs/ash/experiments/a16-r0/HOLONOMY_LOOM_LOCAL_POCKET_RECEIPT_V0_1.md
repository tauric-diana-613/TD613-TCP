## 6. Hard release boundary

The Loom-controlled `COPY FOR CHAT` action must remain disabled until the current draft has been checked.

Any draft/rule/context change relocks the copy door.

If any RED finding remains:

`release_allowed = false`

The copy handler checks that state again before writing to the clipboard.

This is a bounded local guarantee over the Loom-controlled action only.

`LOOM-CONTROLLED COPY GATE != DOWNSTREAM PLATFORM GUARANTEE`

`BLOCKED COPY != IMPOSSIBLE MANUAL EXFILTRATION`

The user may always leave the Loom and manually copy text elsewhere; the prototype makes no browser-sandbox claim against an operator who intentionally bypasses it.
