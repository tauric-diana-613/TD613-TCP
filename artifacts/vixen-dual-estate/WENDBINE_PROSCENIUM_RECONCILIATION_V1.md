## III. Controls, counterfactuals, and stopping

C0 is a prior-day-only title query over the fixed public registry. C1 shuffles source order; the classifier deliberately sorts ties by source ID, making equality a deterministic implementation check **not evidence of reconstruction**. C2 permutes concept labels in the admitted earlier-day training surface. C3 removes typed relation edges from the predictor. C4 selects the actual earlier registered public technical post having minimum title-token overlap with the held-out query (deterministic source-ID tie break). C4 is a source-bound topical decoy, **not a certified semantically independent document**. Every run reports the decoy source ID, prediction, held-out scoring, earlier source-ID witnesses and no scientific credit. Future dated or same-day posts are excluded, including from controls.

The algorithm is a simple deterministic comparator, not an attempt to synthesize an entire authored methodology. Its narrowness is an intentional experimental control, establishing a baseline a richer implementation must beat rather than claiming parity by tool naming.

### Structural 𝄐 · topology-preserving adversarial experiment / Westward two-lens orchestration

The new independent **host-only** operation **wendbine_public_topology_rewire** executes the original TD613 fixture compiler and then a distinct TD613-derived retrospective negative control. It never edits the original compiler, source registries or historical v0.1 protocol. Its source inputs are the 21 earlier-published-day records (September 10, 2026); all 12 September 11 target labels remain held aside until evaluation. The synthetic records are explicit counterfactual test data, never original-post evidence.

**Lens A (graph labels / information aperture).** The existing derived title-disclosed classifier reads ranked source headers, declared concepts, and graph-family edge counts. It does not inspect the directed endpoint connections. Prior query-blind source frequency remains the title-withheld comparator, with matched three-family/five-concept prediction budgets. Because the title-disclosed classifier and query-blind frequency prior are **different predictors**, their scores are **not** a causal ablation estimate of the title. Neither is independent of this post-hoc retrospective archive.

**Lens B (directed relational topology).** For each earlier-day source / graph / evidence-class bucket, the challenge deterministically swaps two destination endpoints that have different origins, without creating self-loops. This keeps the original number of records, per-source graph/relation/evidence labels, and each source node's **directed in- and out-degree** unchanged. It changes which nodes are actually connected. On the registered fixture, 10 constrained swaps alter 20 of 103 earlier-day typed edges. The set of directed two-hop identities loses 12 paths and gains 12 paths while both the original and counterfactual have 44 paths. Raw motif counts alone would miss this structural change. The synthetic edge set has its own digest and is barred from original-source attestation.

**Discriminator.** Evaluate existing C0 on original and rewired earlier-day relations while keeping untouched held-out targets as the scoring surface. Compare original and rewired query-blind frequency controls separately. The present C0 should remain invariant to endpoints; that equality **falsifies an attribution of topology-specific predictive power to this implementation**. It makes no claim about whether the historical author's ideas are topology-sensitive, or whether a future endpoint-aware method could outperform nulls.

**Creative conductor, scoped by admissibility rather than invented ranks:** Aperture asks which information the target's title discloses; Atlas asks which directed paths change under degree-preserving rewiring; Temporal Custodian insists that all training sources precede the held-out publication day and distinguishes a retrospective date from a witnessed observation; FADT checks that the two graph coordinate descriptions preserve the invariants claimed; Pedagogue generates operator inspection tasks only when evidence class and source roles are already bounded. These are **research assignments for the next independently verified orchestration**, not an assertion that all five specialist runtimes executed on original source evidence in this challenge.

**Required external hinge.** Before a distinct prospective experiment acquires target labels, preregister an endpoint-aware comparator, an unchanged graph-label classifier, title disclosure policy, the degree-preserving rewiring seed/rule, target selection and custody, variance assessment, acceptance thresholds and exclusion rules. Require independently obtained, bounded pre-cutoff capture witnesses. If that new witness does not arrive, the correct next action is HOLD, not algorithmic self-certification. No automatic successor stage, historical reconstruction, Vixen performer reclassification, publication or release follows from this assay.
