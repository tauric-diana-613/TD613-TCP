## Working Loom: desktop and mobile

The desktop builder, crossing and return scenes share an 840px maximum centered frame with a translucent blurred surface. Headings, paragraph scale and weight use the same font family as ingress. The same renderer is reparented into the working field; there is no cloned renderer or second scheduler. Its visibility observer follows the active host. Nonempty actual-work packets select a lattice motion family without inserting tutorial-only ambient relation claims.

At mobile widths the frame, padding, radius and field opacity shrink; touch controls wrap and the document scroll remains user-controlled. The 390px battery checks both the empty builder and prepared transfer, repeated scrolling, alternate heights, reduced motion and keyboard focus. The desktop containment repair therefore applies to mobile as a coherent responsive treatment.

Demo-specific continuation controls remain conditional on the Loom-demo route. Ordinary Marrowline keeps its ordinary conversation interface; adding fictional demo controls permanently is not part of this repair.
