## What the Giving specimen taught Pedagogue

The current bundle extends Pedagogue's generic interface diagnosis with six evidence-workflow findings. Giving is the specimen, not the owner of the resulting operators.

### 1. STATUS_ONTOLOGY_OVERCLAIM

A visible status may claim more ontology than the workflow actually established. In Giving, an operator can attribute a retrieved record to a research target; that does not automatically establish person-level identity certainty, legal identity, or compliance authority.

Portable question: **Does the status name the evidence decision that actually occurred, or a stronger conclusion?**

Candidate audit targets elsewhere in TD613: claim-status chips, evidence review cards, profile/actor resolution surfaces, and any UI that converts a bounded record decision into a person-level certainty label.

### 2. LANE_ROLE_PRECEDES_ENTITY

The same name can legitimately appear in multiple evidence lanes while occupying different roles. Giving demonstrates this with contributor and expenditure/payee lanes.

Portable question: **When the same entity appears twice, does the interface teach the role/lane before inviting interpretation of the repeated name?**

Candidate audit targets: any station where one actor/object can appear as source, recipient, custodian, subject, witness, payee, donor, or derived context across adjacent evidence lanes.

### 3. NEGATIVE_RESULT_NEEDS_SCOPE

A zero-result search is an observation inside an aperture, not a global absence claim. Its meaning depends on selected sources, time bounds, query posture, completion receipts, and held/partial routes.

Portable question: **Can the user see what aperture produced the zero before the interface invites a conclusion from it?**

Candidate audit targets: Ash retrieval/search surfaces, Flow-Core context retrieval, Safe Harbor evidence lookups, and other repo search surfaces where missingness could be mistaken for nonexistence.

### 4. ADVISORY_WITHOUT_ROUTE

A warning or diagnostic banner is pedagogically incomplete when it names a condition but gives no bounded route to inspect the affected evidence.

Portable question: **Can the operator move directly from the advisory to the records/state that caused it without the advisory mutating those records?**

Candidate audit targets: warning banners, diagnostic summaries, anomaly counts, drift notices, and calibration advisories.

### 5. DORMANT_CONTEXT_WITHOUT_CONSEQUENCE

A visibly loaded context creates an affordance claim. If the next action ignores that context, the surface should either say “context only” or expose an explicit operator-controlled binding.

Portable question: **Is loaded context visibly consequential, explicitly optional, or misleadingly dormant?**

Candidate audit targets: loaded profiles, selected stations, route context, held capsules, campaign/committee context, and any inspector that displays a selected object beside an action it does not actually constrain.

### 6. RESPONSIVE_ROLE_DRIFT

Responsive design can destroy the spatial relation that originally gave a control its meaning. Shrinking or stacking the control may preserve a false geometry.

Portable question: **At the breakpoint, does this control still have the same semantic role, or should it be reclassified?**

Giving example: desktop sortable column headers become a mobile sort ribbon when contribution cards collapse to one column.

Candidate audit targets: table headers over mobile cards, desktop toolbars that become stacked button grids, legends whose spatial correspondence disappears, and multi-column control groups on narrow screens.

## Additional transfer law reinforced by this bundle

### Evidence-shaped teaching

Practice/demo records should imitate the real field schema while fictionality and teaching authority live in provenance, framing, lineage, or adjacent explanation. Pedagogy should not inject answer-key language into domain fields merely to prove that the record is fictional or anomalous.

### Semantic witnesses over incidental copy

Tests should assert world state, route, authority, and consequence when those are the contract. Exact text remains appropriate where wording itself carries doctrine, safety, provenance, or authority; otherwise incidental copy should not become a brittle substitute for semantic evidence.
