## 0. Question

The hardened transport-tomography assay reconstructs invertible directed edge maps from scalar projections and checks a closed-loop product.

One remaining loophole is that reversed transport was computed by algebraic inversion of the forward reconstruction rather than independently observed.

This assay asks:

> When both orientations of every graph edge are independently observed and reconstructed from scalar projections, do the reverse-edge operators equal the exact inverses of the forward-edge operators, and can an individually reconstructible but orientation-inconsistent control defeat the connection candidate?

The target object is deliberately narrow:

```text
GL(2,F_31)-VALUED ORIENTATION-CONSISTENT GRAPH CONNECTION CANDIDATE
```

This is not a differential connection on a physical manifold.

---

## 1. Base graph

Vertices:

```text
A, B, C
```

Undirected edges with both orientations independently observed:

```text
AB / BA
BC / CB
CA / AC
```

Every orientation receives the same full-rank scalar projection schedule and common held-out probe from the hardened transport-tomography assay.

No reverse operator may be generated by the reconstructor from its forward partner.

## 2. Positive bidirectional fixture

Forward operators remain:

```text
T_AB = [[1,1],[0,1]]
T_BC = [[1,0],[1,1]]
T_CA = [[1,2],[0,1]]
```

Freeze independently authored reverse-edge oracles:


```text

T_CB = T_BC^-1
T_AC = T_CA^-1
```

but the implementation must recover every reverse map from its own scalar observations before comparing it to an inverse.

## 3. Orientation consistency receipt

For each undirected edge `{i,j}`, compute only after both orientations reconstruct:

```text
forward_operator
reverse_operator
forward_inverse
reverse_matches_forward_inverse
forward_times_reverse
reverse_times_forward
left_round_trip_identity
right_round_trip_identity
```

Connection-candidate orientation consistency requires all three edge pairs to satisfy exact identity modulo 31.

If any pair fails, the graph-level connection candidate fails even if every directed edge is individually reconstructible and invertible.

Required anti-equivalence:

```text
EDGEWISE_RECONSTRUCTIBLE_AND_INVERTIBLE
!=
ORIENTATION_CONSISTENT_CONNECTION
```

## 4. Hostile orientation-inconsistent control

Keep all positive operators except replace the independently observed `BA` oracle by:

```text
T_BA_bad = [[1,29],[0,1]]
```

This matrix is invertible and exactly reconstructible under the same projection budget.

However:

```text
T_BA_bad != T_AB^-1
```

The implementation must therefore emit:

```text
ORIENTATION_INCONSISTENT_EDGE_ASSIGNMENT_REJECTS_CONNECTION_CANDIDATE
```

A successful point reconstruction of `BA_bad` may not be treated as support for a connection.

## 5. Loop relation after orientation consistency

Only the positive bidirectional arm may proceed to the triangle loop after all three orientation pairs pass.

Compute:

```text
H_ABC = T_CA T_BC T_AB
```

and independently reconstructed reverse loop:

```text
H_ACB = T_BA T_CB T_AC
```

Required relation:

```text
H_ACB = H_ABC^-1
```

Crucially:

```text
round-trip identity on each individual edge
!=
triangle loop identity
```

The positive fixture is predeclared to have identity round trips on every edge while retaining a nonidentity triangle loop.

That separation prevents local invertibility from being confused with global path closure.

## 6. Gauge covariance

```text

K_B = [[2,1],[1,1]]
```


```text

```

If orientation consistency survives only in one chosen coordinate frame, the connection candidate fails.

6. the positive reverse triangle loop differs from the inverse forward triangle loop;
7. gauge transformation destroys orientation consistency;
8. a reverse operator is derived from the forward operator before its independent observations are reconstructed;
