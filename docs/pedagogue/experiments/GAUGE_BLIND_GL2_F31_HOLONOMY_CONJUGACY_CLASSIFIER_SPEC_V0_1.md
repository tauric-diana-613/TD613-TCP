## 2. Conjugacy fingerprint

For matrix `H`, compute:

```text
trace t = tr(H)
determinant d = det(H)
discriminant Delta = t^2 - 4d mod 31
```

Classify `Delta` as:

```text
ZERO
NONZERO_SQUARE
NONSQUARE
```

For `Delta != 0`, the characteristic polynomial has no repeated root; the bounded fingerprint is:

```text
(t,d,Delta,square_class)
```

For `Delta = 0`, compute:

```text

r = rank(H - lambda I)
```

In dimension two:

```text

r = 1 -> nontrivial Jordan/unipotent class
```

The repeated-root fingerprint must therefore include `r`.

Required anti-equivalence:

```text

!=
necessarily conjugate
```
