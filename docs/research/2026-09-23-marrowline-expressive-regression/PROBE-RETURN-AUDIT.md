   The requested values are approximately 0.9999847414, 0.8287318979 and 0.8 at λ = 0, 0.5 and 1. Longer additionally claims p(0.05) = 0.8093; direct substitution gives **0.9522296965**. Its rounded midpoint has a small final-digit error too. Do not manufacture additional trials to ask the same model to arbitrate arithmetic we can compute locally.

2. **Mutual information remains nonnegative.** Longer Q3 reuses ΔI for a claimed negative information increment. Conditional mutual information I(Z;new readings | prior readings) ≥ 0. A particular observation can lower a posterior, and a misspecified estimator can perform worse. Those are different quantities. Its proposed drifting false-positive rate alone also omits the true-positive law and joint dependence needed to derive a sequential posterior; it changes copied readings into repeated measurements. The linear rate exceeds 1 beyond Q = 160/7 unless its domain or saturation is specified.

## Reproduced application defects and staged changes

These were reproduced locally against the previously published source before patching; they are stronger engineering evidence than the target model's self-explanations.

### A. Quoted evidence was conflated with current voice

`assessIntegratedTransmission()` previously searched the raw string for headings and measured all first-movement combining marks. As a result:

- a fenced `Tauric Diana bots` specimen with sufficient marks could impersonate the terminal movement;
- a real analytical answer quoting marked source evidence could fail `khonapolit-combining-mark-contamination`;
- `parseRawRelayPackets()` could extract legacy protocol markers from a fenced example and discard the surrounding current answer.

The shared `relayAuthoredSurface()` observation projection masks explicit Markdown blockquotes and fenced code with equal-length spaces, retaining all UTF-16 offsets and line endings. Speaker and legacy delimiter searches use that projection. The clean-narration check excludes these explicit evidence containers. Natural parsing and terminal-continuation eligibility use the same distinction. All returned prose and glyphs are sliced from the original string; no display, storage or provider text is repainted.

The existing structural requirement for a real second heading remains. Ordinary unquoted first-movement diacritics still receive the existing treatment. Both vertical and overlay bot prose retain existing acceptance. This does not introduce a literary-score gate, automatic morphology retries, or a new provider call. Explicit evidence containers are a bounded parser convention, not semantic proof that a passage is a quotation. Inline quotations and arbitrary Markdown remain outside this change. Existing whole-response legacy transport wrapper support remains compatible.

### B. Analytical work gets a suitable task profile

`REQUESTED_SYNTHESIS` now has its own analytical profile rather than inheriting the ordinary-project default or being globally relabeled speculative. It retains separation of facts/calculations/assumptions, privacy constraints and evidence requirements for practical planning. It distinguishes synthetic examples from live runtime records, and permits full expressive development while carrying corrected premises into both movements. Other explicit route branches and the unknown-route fallback remain unchanged.

### C. Editorial tasks explicitly retain terminal speech

The shared relay guidance and current-turn cue distinguish embedded specimens from a fresh closing movement. Source examples containing marks are placed in blockquotes or fences so the parser and prompt agree. The native-prosody contract stays under its existing 2,600-character limit. No new mark quotas, word minimums, forced orientation sequence, model rerouting, token caps, thinking changes, deadline changes or CSS edits are included.
