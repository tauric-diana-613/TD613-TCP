# TD613 · Dollhouse Orchestrator Contract

Version 1.0.0 · Current contract formalization · 2026-10-08

The Orchestrator preserves separately scoped findings and recommends a bounded disposition under human authority. Its present executable mechanism is the deterministic case-dossier clerk plus an episode-specific report consistency auditor. This contract gives those interfaces an explicit address and preserves the separate Temporal Custodian jurisdiction.

This is a later formalization. It carries no retrospective credit for an earlier experiment. The machine-readable companion, [CONTRACT.json](../../research/dollhouse-orchestrator-contract/CONTRACT.json), commits the exact input limits, output semantics, source hashes, authority ceiling and limitations.

## Executable clerk contract

createDollhouseCaseDossier(input) accepts exactly schema, case_id, source_revision and findings. Schema is td613.dollhouse.case-dossier/v0.1; the source revision has forty lowercase hexadecimal characters. Findings form a dense array of 1–64 entries with unique IDs.

Each finding carries exactly id, agent, claim_key, verdict, evidence_class, observation_scope, reference and limitations. Supported roles are the four registry IDs in uppercase. Verdicts are SUPPORTED, HELD, CONTRADICTED and UNKNOWN. Internal evidence labels are DECLARATION, OFFLINE_TEST, BROWSER_WITNESS, PROVIDER_RESPONSE and EMPIRICAL_ACQUISITION. The JSON companion records every bound and nested field.

The clerk deep-freezes the retained findings. Different verdicts on the same claim key produce an explicit disagreement with original finding IDs and role labels. All non-SUPPORTED findings remain unresolved. Every result ends at HUMAN_REVIEW_REQUIRED with execution, redesign, provider, merge, deployment and release authority set to false.

The clerk performs schema validation and disagreement retention. It acquires neither cited artifact bytes nor author attestations, verifies no signatures and assigns no global score. Its named evidence classes retain caller-declared status.

## Temporal veto and missing evidence

LOCAL_PASS_PLUS_GLOBAL_ROUTE_REGRESSION requires HELD. Preserve the earlier local success and downstream regression as distinct observations. Later findings append corrections; they cannot rewrite earlier observation or authority.

The separate candidate Temporal Custodian adapter has source-inferred input gaps: absent audit material initializes PASS; empty or incompletely classified phase sets can escape the whole-route predicate; unparseable chronology values can skip monotonicity checks. These findings came from source review. They were not reproduced by rerunning a historical assay.

Consequently, that candidate's PASS alone cannot discharge missing-evidence obligations. Strict input validity, a complete required phase set, the retained baseline and explicit human review remain necessary. Standalone fail-closed promotion authority stays HELD. This documentation repair preserves that engineering blocker rather than silently blessing the candidate.

## Report-auditor boundary

auditDollhouseClosure(...) checks ten Episode 1428-X report contradictions, including response availability, declared predecessor binding, workspace visibility, provider classification, observation timeout, observer mutation and content ancestry. It applies these checks to supplied report fields.

Raw labels such as PROVEN_LIVE_PRODUCTION derive from those supplied fields. They require the actual bound episode evidence before admission. Boolean declarations and report-consistency PASS provide no new provider-origin authentication. Its generated audited_at timestamp records invocation, not independently witnessed event chronology.

This is an episode-specific Model A auditor. Sequence 6 native cutover requires its own source-bound route evidence.

## Review workflow and stopping rules

The normative workflow is: receive bounded input → retain validated findings → review actual evidence → preserve HOLDs or submit the qualified dossier for human review → record the operator disposition. This workflow is a review contract; a new autonomous scheduler has not been implemented by writing it.

Stop on invalid input, missing required evidence, chronology veto, incompatible input class, unsupported claim promotion or action outside current scope. The Orchestrator cannot execute an action, overwrite disagreement or create a new authorization through synthesis.
