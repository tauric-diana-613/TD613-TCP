## Pre-registered source-free comparison

**Unit:** An independent source-free, procedurally constructed finite hearing episode containing an immutable source text digest, source-availability tick, possible subsequent withdrawal, institutional standing label (fictional, no demographic identity), policy label, separate optional consent and attestation gates, a directed nonnegative-cost route network, and declared operator rights.

**Design:** Three fixed strata with 128 generated cases each, in seed-stable order; 384 episodes total. Stopping and sample size fixed in advance. The generator is deterministic, independently versioned and input-only. These are held-out *from the previous one-graph DD-02 toy fixture*, not hidden from the software author, not drawn from real populations, and not external replication.

1. **H0 — basic admissibility:** a finite route with no institutional status-gating, with source availability varied.
2. **H1 — counterfactual standing and consent:** prestige-sensitive or standing-neutral gates, with route detours and operator consent variations.
3. **H2 — withdrawal and type confusion:** prospective withdrawal/revocation, evidence authority types, and a host diagnostic masquerading as source warrant.

**Predeclared methods:**

- **M0 Static incidence baseline (deliberately incomplete)**: shortest nonnegative path on the unconditioned graph, ignoring time, standing, withdrawal, consent, and authority labels. Used only to quantify what a static representation loses; **not** the competent null.
- **M1 Conditional hearing geometry**: typed time-indexed admissible shortest path, based on Dijkstra with explicit source/edge permissions, provenance and clock guards.
- **M2 Competent strong union**: a separately written brute-force simple-path enumeration with access to all the same variables, gates and constraints. No arbitrary handicap, no concealment of policy controls or synthetic source state. Must match the exact mathematical answer wherever M1 claims correctness.

**Primary metric:** Exact agreement with the independent enumerating oracle on reachability and finite minimum path cost, by stratum and overall. Unreachable states use a separate exact token, not a fabricated large cost. A static model may falsely assert a route; this does not establish a strong-union failure. **Novelty surplus:** M1 accuracy − M2 accuracy, with fixed equivalence criterion |difference| ≤ 1/384. No positive surplus in a tie; if M2 is superior, report M1 failure.

**Secondary intervention checks:**

- Holding source bytes and calibration fixed, standing swaps do not alter a standing-neutral policy; any difference under prestige-gated policy is *program-defined*, not evidence that prestige causes real-world behavior.
- Revocation at tick `t_r` removes present/future access but cannot alter an as-of snapshot at `t < t_r`.
- Withheld and unavailable source records are separately recorded, and **no reachable path** implies neither falsehood nor inexistence.
- Giving consent can make additional appeal routes available but never overrides a withheld source, unauthorized host receipt, or revoked rights.
- Ambiance-only changes alter neither path cost nor source/authority fields in these software tests. Effects on human discovery remain **unmeasured**.
- When multiple histories share an equal endpoint cost, returning one scalar cost may erase their distinct route warrants. The model must mark that reconstruction as **non-identifiable from cost alone**, regardless of accuracy on the scalar outcome.

**Negative controls / anti-circularity:** Preserve genuinely disabled gates as disabled in M1 and M2; include edge-order shuffles and irrelevant theme-token swaps; verify source-byte and as-of-time invariance; include explicit alternative paths when direct hearing is closed; include source-authority type errors; record independent implementation differences. A one-graph example, simple formula copied from the oracle, synthetic significance test, or validation that was defined by M1 itself cannot supply independent scientific credit.
