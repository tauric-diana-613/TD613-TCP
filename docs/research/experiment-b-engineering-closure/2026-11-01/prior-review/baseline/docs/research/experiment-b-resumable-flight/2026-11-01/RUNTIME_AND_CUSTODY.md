# Protected runtime, source custody and independent evaluation contract

**Protected path implemented but not exercised or authorized here.** Runtime provisioning and independent acceptance remain Gate F conditions. No operator grant or independent witness credential was generated. Source-free tests cannot mint the original archive capability.

## Authenticated source path

`runner.mjs` requires explicit private configuration, external operator trust roots and an external checkpoint key. It checks finite policies, the operator's signed execution/configuration scope and expiry, runtime-module digest, spanning-quota-window authority and observed runtime binding before calling archive admission. It then invokes the original `ControlledArchiveIntake.admitArchive` with a separately supplied existing archive-admission grant and the original environment guards. There is no source auto-discovery, fallback or bypass.

`protectedBroker` accepts only original in-process members passing `verifyAuthenticatedPhysicalArchiveMember`; it checks them again before rendering a prefix. Copied objects, JSON receipts and matching hashes cannot satisfy that WeakMap check. Broker manifests bind raw-member and admitted-text commitments privately, with exact ordered source-prefix commitments in every intent. A future process restart re-admits the same authorized physical archive under its original admission rules and must match the frozen manifest. Re-admission is a new authorized source operation, not conversion of checkpoint data into authority. Resume therefore requires the operator's source-access policy to permit re-admission; it is not performed under this commission.

The parent retains original source objects. A child receives only inline, prospectively permitted prompt bytes, never the original authorization capability, archive path or the ability to request arbitrary members. The modular second chamber and synthesis receive no raw prefix. Shared deterministic kernels must never expose source files, answers in engine comments, unrelated source identities, later evidence or evaluator material. Existing direct-source restrictions remain part of the frozen protocol; no internal engine is added as research evidence.

Evidence Ancestry, Presentation Ancestry and Adjudication Ancestry must be explicit in each lane's `custodyLineage` and plan binding. They are distinct from invented/raw/derived labels in the synthetic fixture. Approved control representations and evidence withdrawals need their own authenticated private provenance and frozen lane schedules; the runner must not manufacture a new protected source from an unreviewed transform. Every lane/order/replicate is separate; the operator must accept the complete corpus membership and schedule, not just a prefix convenient for resources.

The implementation's native adapter uses the original CLI flags plus the requested effort and retains full returned JSONL. It rejects unexpected CLI activities. Effective sandboxing, provider confidentiality, exact service revision, memory/tool inventories, shell/MCP/search exclusion, effective hard ceilings and absence of hidden native agent calls require runtime evidence and independent acceptance; flags alone do not establish them. A read-only sandbox is not an inter-arm confidentiality boundary. No generic unisolated `spawn` fallback is provided.

The default route permits no CLI tool activity. A permitted deterministic-kernel interface must be provisioned and independently accepted with identical available functions, versions, inputs, tolerances and auditable activity for both architectures. Its requests/results must be retained in `kernelActivity`; wrappers may not use this hook for hidden inference or answer-bearing source access. Arbitrary CLI tools remain refused. This suite tests empty kernel activity and equal pinned bindings, not a live kernel service. Absence or scientific inadequacy of the required kernel service remains a runtime acceptance blocker, not a passed property.

The runtime's measured count is an asserted deterministic measurement, not a provider attestation. The plan's physical allowance and the resource reservation are enforced by the scheduler; actual provider-enforced output/reasoning ceilings and unobservable overhead are not established. Hold if the accepted platform cannot meet the agreed condition. Runtime drift before or after a call preserves the checkpoint and holds the condition; no automatic treatment equivalence is claimed.
