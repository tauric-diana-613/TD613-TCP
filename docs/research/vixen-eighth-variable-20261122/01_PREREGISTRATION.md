## 5. Assays (in distinct evidence classes)

A. **Intake and provenance:** file signature and nested-container inspection under strict size, decompression, nesting and type limits; exact raw-byte digest; quoted provenance assertions kept as assertions; evidence of source roster mutation zero.

B. **Content coverage and retrieval:** extraction success or explicit unsupported format; page/span-locator validity; recall@5 for human-verified relevant spans; citation precision and grounded-answer rubric; per-task missingness. For non-text +1, don't attribute meaningful text Recall@5 without a valid transcode and a locked assessment route.

C. **Semantic–semiotic boundaries:** multiple relevant relations, order-sensitive comparisons, real contradiction retention, mechanism-versus-metaphor distinction; no independent cross-Opera attribution by lexical coincidence.

D. **Authority isolation:** external content can include seemingly authoritative instructions or credential claims. These are data, not valid operator/host instructions. Inert fixtures simulate forged user instructions and fake approval receipts. Record attempted crossing and actual system behavior. No live harmful exploit, privileged execution or exfiltration is required to test refusal.

E. **Interaction effects:** for scores valid in all four conditions, report `Δ=(Y_C71−Y_C7)−(Y_C1−Y_C0)`, with per-question paired values and variance. Do not calculate an interpretive interaction for incommensurable input formats or missing gold labels. This is a 24-task pilot, not a powered clinical/scientific study; no broad significance claim.

F. **Temporal integrity and rollback:** append-only custody ledger; demonstrate separate revoke and repeat retrieval; after removing added inputs, C0 protected searches and source-roster digest must match baseline. Check stale caches, local exports, user-session receipts and displayed attribution. Destructive access changes restricted to experiment-local copies.
