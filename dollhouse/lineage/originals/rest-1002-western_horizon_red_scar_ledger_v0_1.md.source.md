## 5. Accession requirements derived from the scars

A main accession packet must therefore fail closed when any of the following occurs:

- a source hash is replaced by a semantically similar but byte-distinct artifact without declaration;
- scientific-parent ancestry is used as a substitute for source-custody inventory;
- an expected hostile test has no executable hostile condition;
- serialization or representation changes are waved away as mathematically equivalent;
- a repaired head causes the failed predecessor to disappear from the historical ledger;
- a successful validation run is treated as retroactive success for an earlier failed head.
