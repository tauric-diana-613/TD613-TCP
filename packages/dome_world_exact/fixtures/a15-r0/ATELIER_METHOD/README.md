# TD613 Atelier Method v0.1

**State:** research methodology / common kernel / no scientific-promotion authority  
**Date:** 2026-09-11

This method is distilled from three deliberately non-identical TD613 Ateliers:

- **SRC** — sealed epoch/query discipline, authority-vs-chronology separation, evidence-lineage accounting, multi-projection graphs, surface-withdrawal tests, compiler conservation.
- **EMSTD613** — provenance-preserving intake, Work/manifestation identity uncertainty, blind inventory, brutal anatomy, motif-null controls, convergence/divergence, genealogy, emergence, external-science confrontation, red-team disconfirmation.
- **WENDBINE** — public serialized-output compilation, typed relational topology, explicit correction/version events, public/private surface separation, held-out reconstruction, shuffle/permutation/edge-ablation controls.

The purpose of synchronization is **not homogenization**. Each Atelier keeps its own research question, source ontology, evidence geometry, and negative states. The common method standardizes the custody/inference interface so results can be compared without graph-union laundering.

## 1. Common directory grammar

An Atelier should expose, where applicable:

```text
01-MANIFESTS
02-ORIGINALS
03-DERIVATIVES
04-RECEIPTS
05-OPERATIONS
06-INSTRUMENTS
07-ARCHIVE-LEDGER
08-EXTERNAL-CORPORA
99-ADMIN
README.md
CONNECTOR_ENTRY.md
ATTRIBUTION.md
ATELIER_PROFILE.json
```

A missing directory is permitted only when the profile declares why it is inapplicable. Directory presence does not itself establish evidence quality or scientific maturity.

Every Atelier inherits:

```text

HUMAN_PROVENANCE != SOURCE_ASSERTION != ARCHIVE_OBSERVATION != ARCHIVE_INFERENCE
```

Atelier-local membranes may narrow this set further but may not silently weaken it.

## 3. Common evidence ladder

Every proposition must identify the strongest evidence class actually earned:

```text
HUMAN_PROVENANCE
SOURCE_DECLARATION
CAPTURE_FACT
ARCHIVE_OBSERVATION
ARCHIVE_INFERENCE
RESEARCH_HYPOTHESIS
EXTERNAL_WITNESS
EMPIRICAL_SUPPORT
REPLICATED_RESULT
TD613_SCIENTIFIC_PROMOTION
```

Adjacency on the ladder is not automatic promotion. A higher label requires its own witness.

## 4. Common research pipeline

The shared pipeline is modular:

```text
S0 SCOPE + CUSTODY
S1 IDENTITY / MANIFESTATION CONTROL
S2 BRUTAL ANATOMY
S3 TYPED RELATIONAL TOPOLOGY
S4 TEMPORAL / VERSION / AUTHORITY CONTROL
S5 CONVERGENCE / DIVERGENCE / LINEAGE [when relevant]
S6 RECONSTRUCTION / WITHDRAWAL / HELD-OUT TEST
S7 EXTERNAL SCIENTIFIC CONFRONTATION [when relevant]
S8 RED TEAM / ALTERNATIVE MODELS
S9 CLAIM CEILING + NEXT-HIGHEST-INFORMATION TEST + HUMAN RETURN
```

A profile declares which stages are active, inapplicable, or held. Skipping a stage is never inferred silently.

## 5. Four common AIA routes

Each Atelier exposes four non-equivalent views:

```text
EXPERIENTIAL   chronology, concepts, route-conditioned reading
CUSTODIAL      bytes/references, hashes, captures, rights, availability
AUDIT          contradictions, lineage, hypotheses, controls, falsifiers
IMPLEMENTATION schemas, compilers, validators, deterministic tests
```

A comparison may cross routes only when the crossing is named and each route's evidence/authority state remains attached.

## 6. Multiplex topology rule

Graph families remain typed and separable. An Atelier may define local families, but it must not silently collapse dependency, authority, information flow, identity, chronology, provenance, reconstruction, observation, manifestation, bibliography, or conceptual edges into one graph.

Formally:

```text
G_dependency != G_authority != G_flow != G_identity != G_temporal
G_temporal != G_provenance != G_reconstruction != G_observation
```

A conceptual cycle does not establish a historical cycle. A dependency edge does not grant authority. A provenance edge does not prove derivation.

## 7. Negative states are first-class outputs

Ateliers preserve typed absence and uncertainty, including corpus-local states such as:

```text
UNRESOLVED
PLACEHOLDER
OPEN_UNRESOLVED
PRIVATE_UNAVAILABLE
AUTH_REQUIRED
PARTIAL
NOT_RETRIEVED
UNBOUND
AMBIGUOUS_IDENTITY
LIKELY_UNRELATED
```

A negative state may terminate a query lawfully. It may not be rewritten as suppression, falsity, or absence without additional evidence.

## 8. Common finding packet

Every promoted Atelier finding should be representable as:

```text
finding_id

snapshot_or_epoch
entities

projection_or_graph_family
source_span_or_source_refs
evidence_class
evidence_chain
time_coordinates

claim_ceiling
alternative_models

```

This is the **Atelier Interchange Packet**. It is the only common comparison surface. Raw graphs from different Ateliers are not unioned directly.

## 10. Methodological novelty claim

This file does not assert that the individual ingredients above are academically novel. The research candidate is the **composed TD613 Atelier procedure**: provenance-preserving corpus custody + typed multi-projection topology + explicit evidence ladder + identity/manifestation control + held-out/withdrawal reconstruction + adversarial claim ceilings + human closure.

Any novelty claim about that composition requires a separate literature/prior-art assay.

## 11. Human closure and exit

Atelier work is research-only unless separately promoted.

```text
QUERY != MUTATION
OBSERVATION != RELEASE
COMPILATION != PUBLICATION
GREEN_CI != SCIENTIFIC_VALIDATION
ATELIER_SYNC != AUTHORITY_TRANSFER
```

Merge, deployment, release, publication, identity adjudication, and TD613 scientific promotion require explicit human closure under the repository's governing contract.
