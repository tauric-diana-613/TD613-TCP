# Derivatives

Generated analytical aids only. Every derivative must name its exact parent `source_file_id` and SHA-256 plus tool/version and generation time.

Examples:

- extracted text;
- OCR where extraction fails;
- normalized Markdown;
- page maps;
- formula inventories;
- citation inventories;
- section trees;
- embeddings or vector indexes;
- claim-atom candidates;
- motif candidates.

Derivative convenience never outranks original bytes. An extraction defect remains an extraction defect, not a source claim.
