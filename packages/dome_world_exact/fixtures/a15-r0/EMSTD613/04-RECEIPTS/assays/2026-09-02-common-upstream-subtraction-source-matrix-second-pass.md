## New negative control

Citation-family resemblance itself must be typed:

```text
same publisher != same source
same author != same source
same domain != same source
same URL family != same source
same VSM vocabulary != same retrieval path
```

The Dynamic Token correction demonstrates why this matters: treating a related Umbrex glossary or a Kellogg gist as the exact VSM source would manufacture source convergence that the archive does not support.
