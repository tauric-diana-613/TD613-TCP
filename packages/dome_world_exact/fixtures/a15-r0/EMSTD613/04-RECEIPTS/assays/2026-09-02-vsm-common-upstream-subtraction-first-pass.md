## Purpose

This receipt tests whether recurring Stafford Beer / Viable System Model (VSM), algedonic, System-1-through-System-5, and agent-governance language across the preserved Em-selected corpus can be treated as internal lineage evidence.

The answer at this pass is: **not without aggressive common-upstream subtraction**.

The corpus contains a substantial shared contemporary VSM/agent-governance retrieval cluster. That shared bibliography can independently explain a large portion of the apparent recurrence.

This receipt therefore separates:

```text
shared upstream literature
!= Em-internal conceptual migration
!= independent convergence
!= TD613 lineage
```

and asks a narrower question:

> After subtracting the common VSM / agent-governance source cluster, what architectural choices continue to recur in domain-separated Works?

## Method

1. Read the native Markdown Works on the active Atelier branch.
2. Compare exact bibliography items where available.
3. Separate direct source overlap from merely similar terminology.
4. Use domain-separated Works lacking the VSM source cluster as negative/common-upstream controls.
5. Preserve all conclusions as archive inference or lineage hypothesis only.

The more interesting residual appears in Works that do **not** cite Stafford Beer or the VSM cluster at all.

This result cannot be explained by the shared Beer/VSM bibliography because that bibliography is absent here.

## D. Residual candidate: non-self-ratification

The earlier 'lower layer wins' formulation is too crude. The decisive membrane may sit below, above, or outside the proposing subsystem.

The more stable relation is:

```text
HIGH-VARIANCE PROPOSER
!=
SOLE RATIFIER OF CONSEQUENT STATE TRANSITION
```

Observed implementations include:

- Mixxx: AI proposal -> DSP affordance / PhaseClamp;
- Wearable: predictive/AR layer -> direct analog interrupt override;
- Hermes: System-4 proposal -> S3 resource bargaining -> S5 final policy authority;
- OSSL-Seed: probabilistic agent action -> certified sandbox / human cryptographic ratification for high-risk mutation;
- agent-governance Works: generated action -> sidecar / capability / policy enforcement;
- Dynamic Token Allocation: agent execution -> compute-layer abort / credential revocation / HITL escalation.

The topology changes, but the relational predicate can remain:

```text
proposer != court
```

This remains a **lineage hypothesis**, not a lineage finding.

## E. Critical breach / negative control

The semantic memory-culling family provides a counterexample.

In the Hypervisor control-mathematics Work, a latent semantic utility model is allowed to estimate vector importance and feed permanent culling. Earlier analysis found the proxy described as estimating `true semantic utility` without an independently observed measurement bridge for that latent quantity.

That architecture moves toward:

```text
proxy estimate
-> state estimate
-> irreversible deletion authority
```

without the clearly separated independent ratification membrane seen in the stronger safety architectures.

This is useful because it prevents the residual candidate from becoming a universalized doctrine. The corpus contains both the recurring architecture and a plausible violation of it.

## F. Stronger hostile alternatives still active

Even after VSM-source subtraction, the residual is not uniquely attributable to Em.

Competing explanations include:

1. **Generic safety engineering** — E-stops, fail-shut systems, hard-real-time isolation, authorization boundaries, and HITL gates are standard engineering patterns.
2. **Common research-tool synthesis** — a model may independently prefer architectures that separate stochastic proposal from deterministic enforcement.
3. **Task constraints** — physical audio, drone safety, enterprise governance, and legal state mutation naturally demand stronger authority membranes than purely expository work.
4. **Selection effect** — the hand-selected corpus may overrepresent systems architecture and therefore overrepresent guardrails.

These alternatives remain live.

## G. What would strengthen the residual

The non-self-ratification candidate earns more weight only if future archaeology shows one or more of the following:

- the same relation appears in additional Works without VSM/agent-governance source overlap;
- the relation appears before the explicit VSM vocabulary in recoverable chronology;
- later Works repair earlier failures specifically by inserting an independent authority membrane;
- wording, diagrams, or uncommon implementation choices migrate across domains while upstream sources differ;
- source-prompt residues show the relation was requested by Em rather than supplied by retrieval;
- the relation survives supported-identity collapse/split sensitivity.
