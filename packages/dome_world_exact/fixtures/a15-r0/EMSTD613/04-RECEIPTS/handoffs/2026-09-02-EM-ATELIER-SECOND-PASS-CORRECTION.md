# I. Major methodological correction: Work != uniform assertion surface

A Work contains multiple speech-act zones with different evidentiary authority. Relevant observed strata include:

- retained user/task prompt residue;
- generated research exposition;
- source/system specification under review;
- proposed or illustrative implementation;
- embedded executable prompt/configuration surface;

- future research prompt;
- bibliography/upstream literature.

Therefore:

```text

!= UNIFORM ASSERTION SURFACE
```

and:

```text

illustrative code != deployed implementation
generated exposition != necessarily originating premise
source specification under review != independent empirical validation
```
