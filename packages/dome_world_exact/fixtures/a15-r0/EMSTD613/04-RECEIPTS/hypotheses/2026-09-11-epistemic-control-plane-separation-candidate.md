# Epistemic Control-Plane Separation Candidate

Date: 2026-09-11  
Status: HIGH-VALUE HYPOTHESIS / NOT EARNED TD613 OR DOME-WORLD RESULT

## Motivation

The corrected seventh Batch-B source supplies three distinct control jurisdictions inside one Work:

1. representation / attention steering,
2. explicit fact preservation through DSR-style symbolic shielding,
3. physical robotics control with explicit low-level plant dynamics.

The Atelier separately carries directional receiver-contract and exterior-witness constraints.

A potentially useful architecture emerges if these are kept separate rather than unified rhetorically.

## Three-plane candidate

```text
S-PLANE — SEMANTIC / BEHAVIOR CONTROL
activation vectors
attention allocation
style / policy target
PID / gradient / energy guidance

W-PLANE — WITNESS / FACT CONTROL
source identity
external observation
fact-bearing values
acquisition time
provenance / confidence / claim ceiling

A-PLANE — ACTUATOR / PHYSICAL CONTROL
sensor state
plant state
physical clock
command units
receiver / cancellation / actuator semantics
```

Hard non-equivalence:

```text
S != W != A
```

Typed crossings:

```text
W -> S
reference constructor / fact injection

S -> W
claim candidate requiring validation

S -> A
plan / command proposal through actuator contract

A -> W
physical observation with custody

A -> S
telemetry interpreted into semantic state
```

No crossing inherits the authority class of its source merely because a vector, scalar, or label can be computed.

## Minimal experimental battery

Compare at least three systems under matched base models and tasks:

```text
SYSTEM A
semantic steering only

SYSTEM B
semantic steering + protected fact plane

SYSTEM C
semantic steering + protected fact plane + external witness claim ceilings + typed actuator boundary where applicable
```

Adversarial conditions:

1. internally coherent false context,
2. stale once-correct context,
3. conflicting retrieved sources,
4. poisoned reference constructor,
5. style target that pressures protected entities,
6. witness outage,
7. repeated self-attestation with no new evidence,
8. physical action proposal with missing / delayed telemetry,
9. high semantic confidence paired with low witness confidence,
10. rapidly changing external fact while semantic state remains stable.

Measures:

```text
unsupported factual claim rate
verified-entity preservation
claim calibration
reference-tracking error
behavior-control success
receiver rejection / hold correctness
false-actuation rate
latency
recovery after stale / poisoned reference
performance under witness outage
```

## Falsifiers

The candidate loses value if:

- the separated planes do not improve factual / actuation safety at matched task performance;
- the overhead dominates gains;
- a simpler calibrated single-plane baseline performs equivalently;
- protected facts introduce comparable or worse failure modes;
- the claimed benefits arise only from extra compute or retrieval rather than jurisdiction separation.
