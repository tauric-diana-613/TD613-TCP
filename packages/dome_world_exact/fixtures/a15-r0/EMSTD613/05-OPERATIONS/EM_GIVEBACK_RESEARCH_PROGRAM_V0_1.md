# EMSTD613 Giveback Research Program v0.1

Status: RESEARCH PROGRAM / NO PROMOTION / NO PRODUCTION MUTATION

## Purpose

The EMSTD613 Atelier has extracted useful questions from Em-selected work. The giveback obligation is to return something more useful than critique: a bounded research program in which Em's strongest recurring ideas can win, lose, or narrow under explicit controls.

This program does not attribute the derived mechanisms to Em as authorial intent. It records that the EMSTD613 corpus materially motivated the assay family.

## Track A — Reference Authority Stress Test

Candidate contribution:

```text
REFERENCE_AUTHORITY_TRAVELS_WITH_CONTROL_TARGET
```

Question:

> Can semantic/behavioral control remain strong while the factual authority of the reference is false, stale, conflicting, or unobserved?

Matched conditions:

```text
A1 true + fresh target
A2 false but semantically coherent target
A3 once-valid but stale target
A4 conflicting witness target
A5 target with withheld provenance
```

Hold controller architecture and target geometry as constant as possible.

Primary measurements:

```text
semantic tracking error
behavioral task score
reference-validity error
stale-target persistence
abstention / hold rate
unwarranted factual confidence
```

Success condition for the candidate:

> Explicit witness/reference binding lowers false/stale-reference acceptance without materially destroying valid semantic-control performance.

Failure condition:

> A simpler controller without separate reference-authority state matches or exceeds both control performance and factual reliability.
