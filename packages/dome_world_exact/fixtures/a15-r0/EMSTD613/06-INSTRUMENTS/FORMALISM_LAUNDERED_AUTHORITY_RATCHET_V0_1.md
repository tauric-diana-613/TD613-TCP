# Formalism-Laundered Authority Ratchet v0.1

Status: RESEARCH-ONLY / EMSTD613 Atelier

## Discovery

The bizarre panel exposes a recurrent claim-transition pattern that is more specific than generic ontology inflation.

```text
structural analogy
-> imported formal vocabulary
-> equation / named theorem / geometric object
-> apparent mechanism closure
-> external-world claim
```

The dangerous transition occurs when formal enrichment of the description is treated as if it supplied a new empirical witness.

Define conceptual route depth `F` and authority-route support `W`.

A claim may increase `F` while `W` remains unchanged:

```text
F(t+1) > F(t)
W(t+1) = W(t)
```

If claim scope simultaneously expands,

```text
S(t+1) > S(t)
```

then the artifact has accumulated `formalism_laundered_authority`.

## Ratchet form

The failure is especially potent because each formal layer makes the next promotion feel locally justified:

```text
analogy
-> notation
-> theorem-name
-> cross-domain mapping
-> mechanistic language
-> ontological language
-> engineering/clinical/historical claim
```

No single hop need look absurd. The global path can still exceed the original warrant.

Therefore:

```text
LOCAL RHETORICAL PLAUSIBILITY != GLOBAL CLAIM-PATH VALIDITY
```

This is the epistemic analogue of authority-composition laundering.

## Bizarre-source signatures

### Myth Transmission
Cultural contact is redescribed through Shannon-Hartley/rate-distortion/state-space/matrix-completion/quantum-observer machinery. Some of those frameworks can be useful analogical or computational models. Their mere mathematical availability does not establish that historical transmission instantiates the physical/information-theoretic quantities literally.

### Cognitive Singularity
Information geometry supplies legitimate mathematical objects. The artifact then promotes degeneracy/curvature/geodesic deviation into literal claims about identity fracture, DID, event horizons, tunneling, and cognitive spaghettification without a separately established measurement map from neural/clinical observables to the asserted manifold quantities.

### Quantum Topology / Wormholes
Highly domain-specific quantum-gravity/QFT results are progressively narrated as an engineering pathway. Constraint results remain informative; the engineering affordance accumulates authority debt where scale, realizability, and experimental bridge are missing.

### Theremin Drone Glove
The engineering mechanism is already expressible through capacitance, resonance, impedance, filtering, sensor fusion, and control. QFT/vacuum-boundary language therefore provides a strong test for `EXPLANATORY_SURPLUS_WITHOUT_OPERATIONAL_GAIN`.

### 1+1=3
Multiple frameworks are made mutually reinforcing by shared vocabulary of boundary, re-entry, time, closure, play, thermodynamics, and autonomy. The assay must distinguish genuine composable relations from semantic braid density.

## New diagnostic: witness-to-formalism ratio

For a claim transition `c_i -> c_j`, record:

- `delta_formalism`: new equations, named mathematical objects, or formal mappings;
- `delta_witness`: new independent measurement, source-specific calibration, experiment, or validated bridge;
- `delta_scope`: expansion in domain or ontological force.

High-risk transition:

```text
delta_formalism >> 0
delta_witness = 0
delta_scope > 0
```

This is not a universal numerical score. It is a typed diagnostic pattern.

## Salvage law

The presence of formalism-laundered authority does not invalidate the underlying mechanism.

Strip the unsupported promotion and ask whether a lower claim level survives:

```text
A6 external-world claim fails
-> test A4 operational model
-> if A4 fails, test A3 mechanism hypothesis
-> if A3 fails, retain A1/A2 analogy
```

This is `CONTROLLED_DECOLLAPSE_BY_CLAIM_LEVEL`.

## Devastation test

A theory that survives only while its analogies remain fused is not robust.

For every bizarre work:

1. remove the grandest ontology;
2. preserve only independently defined variables and operations;
3. rerun the mechanism description;
4. record what explanatory or predictive capacity actually disappears.

If nothing operational disappears, the ontology was decorative authority.

If a measurable prediction disappears, the ontology may encode a real mechanism candidate and deserves a separate assay.

MODEL COMPLETENESS != WORLD COMPLETENESS

## Falsifier

The ratchet weakens if claim-atom reconstruction shows that apparent scope expansions were already explicitly licensed by source-specific empirical bridges, or if stripping the allegedly decorative ontology destroys unique, testable predictions that simpler models cannot reproduce.
