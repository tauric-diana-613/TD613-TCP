# Motif-to-Mechanism Translation Firewall

Motifs are excellent search apertures and terrible automatic proofs.

For every recurrent motif, ask:

1. What exact source spans instantiate it?
2. What field-generic alternatives could explain recurrence?
3. Does the motif map to the same entities, operators, boundary conditions, and predicted consequences?
4. Can a mechanism be written without using the motif's metaphorical vocabulary?
5. What observation would distinguish shared mechanism from shared rhetoric?

Promotion ladder:

```text
MOTIF_MATCH
-> STRUCTURAL_ANALOGY_CANDIDATE
-> MECHANISM_CANDIDATE
-> MECHANISM_SUPPORTED
```

Skipping rungs is forbidden.
