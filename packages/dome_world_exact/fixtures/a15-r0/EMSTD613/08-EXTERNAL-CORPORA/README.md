# External comparative corpora

This room stores pointers, manifests, and assay receipts for evidence outside Em's source folder.

## Comparison classes

### TD613 repository

Use exact commit/path/receipt anchors. A TD613 theorem label or instrument name is a comparison target, not proof of Em-side lineage.

### SRC Atelier

Treat SRC as a separate archival/research projection. Never join SRC source claims, archive inferences, or TD613 interpretations implicitly.

### Retrieved conversation memory/history

Memory can recover research questions, aliases, prior hypotheses, and prior workflow context. Label it `RETRIEVED_RECOLLECTION`. It cannot independently prove a historical event, platform cause, or source-text claim.

### Current science

Prefer primary literature and primary technical evidence. Record:

```text
publication_date
version
peer_review_status
DOI or canonical identifier
method
dataset/code availability
replication status
relevance dimension
```

For applied AI/platform questions, distinguish product documentation, standards, source code, benchmark evidence, incident reports, and controlled reproduction.

## Breakthrough discipline

A work described publicly as a “breakthrough” enters as a recent external witness. The Atelier separately asks what changed technically, how the result was measured, whether the effect replicated, and which Em/TD613 mechanism—if any—it discriminates between.
