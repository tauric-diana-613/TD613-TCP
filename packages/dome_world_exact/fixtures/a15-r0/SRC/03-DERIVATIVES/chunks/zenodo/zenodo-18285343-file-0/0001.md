Observation When a Zenodo DOI was pasted into an Academia.edu essay, the following pattern emerged:

• Google indexed the page rapidly, surfacing it in search results shortly after publication. • Bing did not index the page at all, even after repeated checks. • The page was publicly accessible in both cases. • The only variable that changed between indexed and non ‑ indexed versions was the presence of
