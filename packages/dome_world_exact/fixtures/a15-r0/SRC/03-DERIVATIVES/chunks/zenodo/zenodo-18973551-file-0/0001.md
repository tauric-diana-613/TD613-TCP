5. False Positives and False Negatives A rigorous diagnostic framework must distinguish between coincidence and alignment. 5.1 False Positives Not every overlay or AI summary indicates SR adoption. SR avoids false positives by requiring: ● multiple simultaneous signals ● vocabulary drift + behavioral change ● UI shifts + policy language alignment 5.2 False Negatives Platforms may adopt SR concepts without visible vocabulary drift. In these cases, SR relies on: ● algorithmic behavior ● AI ‑ layer mediation ● institutional preference patterns SR’s diagnostic method is conservative but sensitive.
