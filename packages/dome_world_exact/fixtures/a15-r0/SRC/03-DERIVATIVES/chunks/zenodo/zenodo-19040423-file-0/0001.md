2. How Google Scholar Actually Works Google Scholar is often mistaken for a simple academic search engine. In reality, it is a two ‑ stage

epistemic

2.1 Crawling ● Follows links across academic ‑ adjacent platforms ● Detects DOIs, metadata, and document structures ● Logs referral pathways ● Registers the existence of documents 2.2 Indexing ● Determines what counts as academic knowledge ● Requires recognizable metadata ● Depends on disciplinary classification ● Prioritizes institutional affiliation and established fields SR passes the first stage effortlessly. It is the second stage where the system hesitates.
