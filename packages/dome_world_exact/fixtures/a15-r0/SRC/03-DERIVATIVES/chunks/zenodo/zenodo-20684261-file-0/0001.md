3.1 The Web as a Navigational Institution

From its inception, the web was structured around the metaphor of movement : users “visited” pages,

“followed”

These

● interpreting visual layouts ● deciding where to go ● clicking through structures ● filling forms ● navigating hierarchies The hyperlink was the atomic unit of this navigational logic. It represented both a technical pointer

and

The

This assumption held for nearly three decades.
