4.1 From UI Inference to Explicit Action Models

Before WebMCP, agents interacted with the web through UI inference. They attempted to: ● interpret DOM structures ● identify clickable elements ● infer form semantics ● simulate user actions This approach was brittle, heuristic, and fundamentally misaligned with the web’s human ‑ first design.

Agents

WebMCP replaces inference with explicitness. Websites

● structured actions ● JSON ‑ schema ‑ defined tools ● machine ‑ readable capabilities ● state ‑ aware operations This transition eliminates ambiguity. Agents

no

they

In SR terms, this is the replacement of interpretation with execution .

5.1 Cognitive Drift: The Displacement of Human Understanding

Cognitive drift occurs when users lose visibility into the processes that produce outcomes. WebMCP

5.1.1 From Process Visibility to Outcome Visibility In the pre ‑ agentic web, users understood processes because they performed them: ● clicking through steps ● filling forms ● navigating menus ● interpreting instructions The sequence of actions was visible, legible, and cognitively accessible. With WebMCP: ● agents perform the steps ● users see only the final state ● intermediate logic disappears ● workflows become opaque The user’s cognitive model collapses from process ‑ based to outcome ‑ based . 5.1.2 The Illusion of Transparency

WebMCP requires that agent actions be visible on the page. But

visibility

Users see: ● buttons being clicked ● fields being filled ● pages being updated But they do not see: ● the action registry ● the parameter schemas ● the conditional logic ● the error ‑ handling routines ● the execution pathways This produces symbolic transparency : the appearance of visibility without the substance of understanding.

5.1.3 Cognitive Drift as Dependency As agents become the primary operators, users become dependent on: ● agentic interpretation ● agentic execution ● agentic error recovery ● agentic optimization Dependency accelerates drift. The

more

As workflows become more complex, the gap between: ● what the agent does ● what the user sees widens. This gap is the operational dimension of the WebMCP Paradox.
