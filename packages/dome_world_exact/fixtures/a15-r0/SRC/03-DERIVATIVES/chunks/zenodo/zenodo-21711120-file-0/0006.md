CHAPTER 8A — FIRST EMPIRICAL VALIDATION OF THE DRIFT COLLAPSE FIELD

Response-Capacity-Relative Drift in U.S. Electric Distribution Systems, 2014–2024

8A.2 The Simple Drift-Amplification Hypothesis Let routine reliability strain in division d and year t be:

RS_{d,t} = SAIDI^{Routine}_{d,t}

where SAIDI^{Routine} is annual SAIDI with major events removed.

Let major-event excess burden be:

MEB_{d,t} = SAIDI^{All}_{d,t} - SAIDI^{Routine}_{d,t}

The first hypothesis is:

H1: RS_{d,t-1} → MEB_{d,t}

or, in regression form:

ln(1 + MEB_{d,t}) = α + β_ RS ln(RS_{d,t-1}) + ε_{ d,t}

with the directional prediction:

β_ RS > 0.

This is intentionally a demanding interpretation of routine strain. If elevated pre-event routine interruption

burden

contains

information

about

latent

deterioration

or

reduced

adaptive

margin,

it

should

help

predict

the

additional

burden

realized

when

major-event

conditions

occur.

8A.3 Why the Pooled Test Is Not Enough A positive pooled association can arise even when no dynamic drift process exists. Regions differ

persistently

in

storm

exposure,

vegetation,

network

topology,

undergrounding,

terrain,

utility

structure,

infrastructure

age,

maintenance

regimes,

and

other

characteristics.

DCF

must

therefore

distinguish:

structural difference ≠ directional deterioration.

The stronger within-system model is:

ln(1 + MEB_{d,t}) = α_ d + β_ RS ln(RS_{d,t-1}) + ε_{ d,t}

where α_ d absorbs persistent Census-division differences.

The strongest specification adds common year effects:

ln(1 + MEB_{d,t}) = α_ d + λ_ t + β_ RS ln(RS_{d,t-1}) + ε_{ d,t}.

If β_ RS remains positive under these controls, the interpretation becomes considerably more consistent

with

dynamic

strain.

If

it

collapses

toward

zero,

routine

SAIDI

is

not

a

sufficient

empirical

representation

of

DCF

drift.

8A.5 Descriptive Result Across the panel, routine interruption burden and major-event excess are positively related in the raw

data.

The

is

r = 0.420.

The pooled lagged model produces:

β̂_ RS = 1.907, SE = 0.420, p < 0.001, R² ≈ 0.182.

At this stage the result appears favorable to the simple DCF hypothesis: divisions with greater routine

But this is not the crown result. The field must survive stronger controls.

8A.6 Division Fixed-Effects Test After persistent division differences are absorbed, the estimate falls substantially:

β̂_ RS = 0.884, SE = 0.969, p = 0.361.

The sign remains positive but the estimate is imprecise and statistically indistinguishable from zero.

The

from

indicates

is

stable

between

rather

This result directly constrains DCF interpretation. A region can be chronically vulnerable without

High

is

8A.7 Division-and-Year Fixed-Effects Test When both persistent regional differences and shared year conditions are controlled, the estimate becomes:

β̂_ RS = -0.289, SE = 0.873, p = 0.740.

The coefficient is statistically indistinguishable from zero and its sign reverses. Under this specification,

prior-year

routine

SAIDI

does

next-year

major-event

The central empirical conclusion of the first DCF test is therefore:

RoutineSAIDI_{t-1} ↛ MajorEventExcess_t

under the strongest tested panel controls.

This is a null result for the simple drift-amplification proxy hypothesis.

8A.9 Comparative Predictive Test DCF must also compete against simpler models. A variable should not be retained merely because

it

can

be

given

an

SR

name.

Define a simpler predictive model:

M0: ln(1 + MEB) = f(division, time)

and the DCF-augmented model:

M1: M0 + ln(RS_{t-1}).

Using leave-one-year-out prediction, the estimated root-mean-square errors are:

RMSE(M0) = 0.7745 RMSE(M1) = 0.7863.

Define improvement so that a positive value favors DCF:

Δ RMSE = RMSE(M0) - RMSE(M1).

Then:

Δ RMSE = -0.0118.

The added routine-strain proxy slightly worsens out-of-sample predictive error. Thus, on this test:

Δ Perf_DCF < 0.

The first candidate DCF variable does not earn retention through predictive performance.

8A.10 What Failed—and What Did Not The failed proposition is not “systems can deteriorate” and it is not “extreme events can expose vulnerability.”

Both

propositions

are

already

well

established

in

resilience

research.

What

failed

here

is

narrower:

high or worsening routine interruption burden alone is not sufficient to identify the latent response-capacity-relative

state

proposed

by

DCF.

The null result reveals an important construct distinction:

Level ≠ Drift.

A system can perform poorly at a stable level. A system can perform well while deteriorating. A system

can

also

improve

from

a

poor

baseline.

DCF

therefore

requires

a

directional

measure

rather

than

treating

adverse

level

as

8A.11 Drift Velocity A stronger operationalization begins with change rather than state level. For observable indicator X:

DV_{d,t}^{(k)} = (X_{d,t} - X_{d,t-k}) / k.

DV is Drift Velocity over a k-period window. The direction of X must be defined in advance so that

positive

DV

consistently

represents

increasing

pressure.

A multi-indicator version is:

DV_{d,t} = Σ_ j w_j · ∂X_{j,d,t}/∂t.

The weights w_j cannot be assumed merely for convenience. They require either transparent theoretical

justification,

measurement-model

estimation,

or

sensitivity

analysis.

8A.12 Response-Capacity Divergence The central DCF object after the first empirical test becomes more precise. Let P represent structural

pressure

and

C

effective

response

capacity.

Define

pressure-capacity

divergence

as:

PCD_{d,t} = Ṗ_{d,t} - Ċ_{d,t}.

When:

PCD_{d,t} > 0,

pressure is increasing faster than capacity. When:

PCD_{d,t} < 0,

capacity is improving faster than pressure, or pressure is declining faster than capacity.

A ratio form can also be used where denominators are substantively meaningful:

PCR_{d,t} = P_{d,t}/C_{d,t}.

The ratio and derivative formulations answer different questions and should not be substituted for

one

another.

PCR

describes

state

relative

to

capacity;

PCD

describes

directional

divergence.

8A.13 The Stronger Shock-Interaction Test

The next decisive DCF test should observe shock intensity directly. Let S_{i,t} denote exogenous

shock

intensity

and

D_{i,t-1}

prior

measured

drift.

Estimate:

Y_{i,t} = α_ i + λ_ t + β_1 S_{i,t} + β_2 D_{i,t-1} + β_3( S_{i,t} × D_{i,t-1}) + γ X_{i,t} + ε_{ i,t}.

The key DCF coefficient is:

β_3.

If:

β_3 > 0,

then comparable shocks produce larger adverse outcomes in systems with greater prior drift, conditional

on

relevant

exposure

and

structural

controls.

This is stronger than asking whether vulnerable systems have large failures. It asks whether measured

prior

directional

divergence

modifies

the

effect

of

a

subsequent

shock.
