8A.17 Five-Level Empirical Testing Ladder The first test indicates that DCF needs an explicit progression of empirical difficulty.

Level 1 — State test: Do proposed indicators measure distinct, reliable system states?

Level 2 — Velocity test: Do changes in those states exhibit persistent direction beyond ordinary fluctuation?

Level 3 — Capacity-gap test: Does pressure grow faster than effective adaptive or repair capacity?

Level 4 — Shock-interaction test: Does prior drift amplify the effect of comparable subsequent shocks?

Level 5 — Comparative survival test: Do DCF variables improve out-of-sample prediction, mechanism
