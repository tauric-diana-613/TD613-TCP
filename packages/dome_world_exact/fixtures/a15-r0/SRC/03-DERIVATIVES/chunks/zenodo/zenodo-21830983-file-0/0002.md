SR is an open metatheory. It exposes its matrix to adversarial testing. It accepts adversarial collaboration. It allows competing metatheories to challenge it. It also requires competing metatheories to be challenged in return. It studies not only systems, but the theories used to describe systems. A.4 Anomaly Visibility Anomaly visibility may be represented as: V = E × D × T where D represents diagnostic sensitivity and T represents temporal traceability. Higher visibility should, under ordinary conditions, increase the probability that anomalies
