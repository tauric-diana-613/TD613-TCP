25.1 Endogenization Let X_s(t) be substrate conditions and P(t) policy. Conventional analysis may assume: P(t) → X_s(t) → Y(t) SR adds feedback: Y(t) → P(t+1) and: P(t) → X_s(t+1) → P(t+1) Policy therefore becomes part of the system it is intended to govern. 26.1 Five Institutional Cognition Tests 20.

Recognition test — does the institution recognize the relevant condition? 21.

Attribution test — does it attribute the condition to the correct causal level? 22.

Integration test — can it connect evidence across institutional boundaries? 23.

Response test — can recognized causes be translated into action? 24.

Learning test — does the institution update after intervention failure? Failure at any stage can generate a policy problem that persists despite apparent responsiveness.

CHAPTER 30 — WEIGHTING, CALIBRATION, AND UNCERTAINTY Composite indices can become arbitrary if weights are hidden. SR therefore requires explicit

weighting

Weights may be derived from theory, empirical concentration, expert elicitation, entropy-based

methods,

or

estimated

latent

structures.

Each

be

disclosed. Researchers should publish sensitivity intervals rather than a single supposedly exact score. For a composite index Q = Σ w_i x_i, uncertainty should be propagated through the weights

30.1 The Rule Against False Precision SR does not claim that a structural index is scientific merely because it contains decimals. Numerical precision must correspond to measurement reliability. The appropriate output may be an interval, distribution, ordinal classification, or posterior estimate

a

single
