4. Epistemic Leverage of Infrastructure As AI systems became embedded in organizational workflows, researchers increasingly

This sequence created epistemic leverage : ●

The infrastructure contains internal physics. ●

The fields lack visibility into those physics. ●

The infrastructure behaves as a black box. ●

The fields operate on assumptions of stability.

This leverage is not political; it is structural. The

The

do
