29H.5 Triangulated Loop Result The present evidence therefore supports each component transition in separate empirical environments:

F_t → Q_{t+1}: supported by targeted-funding response evidence.

Q_funded,t / F_t → K_{t+1}: supported by NIH grant-to-publication causal and longitudinal evidence.

K_t → F_{t+1}: strongly supported predictively in NIH career-development cohorts.

F_t → F_{t+n}: strongly supported by disease-category funding persistence.

The combined architecture is therefore:

F_t → Q_{t+1} → K_{t+1} → F_{t+2}
