APPENDIX B — SR-RIF MINIMUM EMPIRICAL REPORTING STANDARD 1. Define the stage of the knowledge-production chain being studied. 2. State the population denominator for that stage.

3. Define the transition event and estimand. 4. Separate scientific-quality controls from institutional variables. 5. Do not infer motive from association. 6. Report absolute as well as relative effects where feasible. 7. Report heterogeneity and domain boundaries. 8. Preserve null results and contrary findings. 9. Do not code missing incentive variables as evidence of hidden incentives. 10. Predefine materiality for transparency studies. 11. Separate exploratory protocol development from confirmatory analysis. 12. Apply the same standards to SR-generated evidence. APPENDIX C — SR-RIF EMPIRICAL TEST 2 CALCULATION For each reported selection ratio η ᵢ with 95% confidence interval [Lᵢ, Uᵢ], the log-scale standard error

was

reconstructed

as:

SE(log η ᵢ) = [log(Uᵢ) − log(Lᵢ)] / (2 × 1.96) Inverse-variance weights were: wᵢ = 1 / SE(log η ᵢ)² The fixed-effect weighted log mean was: μ̂ = Σ wᵢ log( η ᵢ) / Σ wᵢ Cochran's heterogeneity statistic was: Q = Σ wᵢ[log( η ᵢ) − μ̂]² For four environments, df = 3. The reconstructed result was Q = 16.54, producing p ≈ 0.00088. I² = max(0, (Q − df)/Q) × 100% ≈ 81.9%
