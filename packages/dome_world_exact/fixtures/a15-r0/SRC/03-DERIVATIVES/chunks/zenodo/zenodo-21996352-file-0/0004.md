25C. Displacement Efficiency Recycling should be evaluated by whether additional secondary material actually

SR

DE = -Δ P_primary / Δ P_secondary A value near 1 indicates that each additional unit of secondary production corresponds

A

0

A

primary

and

Using OECD’s Global Lifecycle High-stringency 2040 totals as an illustrative

2020

plastics

are

approximately

94%

of

435

Mt,

408.9

Mt.

A

60

Mt

approximately

348.9

Mt

With
