Layer Symbol Primary object Examples Structural test Behavioural regulation R_B Behaviour inside an existing system household recycling, conservation prompts, consumer incentives Did behaviour change while architecture remained intact? Output regulation R_O Outputs or externalities of an operating system emissions standards, methane controls, carbon accounting, pollution treatment, recycling systems Did output intensity fall without equivalent change in productive capacity? Architectural regulation R_A The infrastructure and productive architecture itself capacity retirement, production constraints, extraction limits, infrastructure replacement, binding substitution Did the system's reproductive capacity change?

The
