Appendix B. Status Definitions

Status

Definition

Canon node

Foundational work required to understand SR grammar, mechanisms, or measurement.

Supporting canon

Operational, explanatory, or methodological work strengthening a canon node.

Core research program

Durable cross-domain program with distinct questions and reusable methods.

Domain research program

Domain application of SR mechanisms; not an independent discipline by default.

Merge candidate

Substantially overlaps a stronger synthesis.

Revision or duplicate

Earlier, copied, imported, or overlapping edition.

Administrative or translation

Licensing, governance, public explanation, or creative work outside the scientific canon.

Review

Insufficient evidence for a final decision.

Archive

Retained for provenance but not required in the active canon.
