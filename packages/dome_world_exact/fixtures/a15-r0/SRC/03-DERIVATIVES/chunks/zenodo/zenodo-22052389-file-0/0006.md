20. Falsification and Demotion Conditions Falsification target Condition that weakens or defeats the claim Surface sufficiency If standard surface indicators repeatedly predict relevant outcomes as well as deeper reconstructions, SI adds no value. No compensation signal If requirement-capacity gaps do not precede or covary with extraordinary compensation, the compensated-continuity mechanism weakens. No recovery response If independently measured restoration of durable capacity does not reduce extraordinary compensation or improve effective access, the restoration branch fails. No incremental validity If M_CS does not improve held-out explanation/prediction over strong domain baselines, Collapse Society should be demoted to a framework. Construct non-discrimination If SI, BT, C_E, Dep, or V_E cannot be distinguished from established constructs, SR terminology should be narrowed or merged. Reverse causality dominates If outcomes consistently produce the supposed exposure architecture rather than the reverse, causal claims must be revised. Voluntary/healthy compensation If supposed burden transfer is predominantly chosen, sustainable, and not linked to gaps, it should not be classified as erosion. Cross-domain non-portability If SSR only works in one domain and fails elsewhere, field-level generality is weakened. Epistemic counterexamples If mediation, ranking, automation, or metrics improve provenance, correction, and decision quality, they must be classified as restoration or neutral mediation rather than collapse. National overreach If local or subgroup inversions do not aggregate to national conditions, the field must not infer a national collapse state.

Appendix B. Minimum SSR Reporting Standard •

State the formal surface variable and its measurement source.

•

State the contradictory outcome independently; do not define inversion with the same

variable

used

as

the

outcome.

•

Specify Q, D, Dep, Alt, BT, C_E, V_E, O, and R only where they are actually measured.

•

Label inferred nodes as inferred; do not convert missing measurements into numbers.

•

Report nulls, countertrends, and restoration cases. •
