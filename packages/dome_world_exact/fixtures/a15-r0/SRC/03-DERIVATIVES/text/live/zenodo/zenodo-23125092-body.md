Representational Displacement: How Proxy Representations Become Operative Objects and Displace Ground Reconstruction in Institutional Systems 

 DESCRIPTION 
 Representational Displacement is an SR Institutional Governance mechanism describing the condition in which a representation—metric, category, file, model, dashboard, audit, or algorithmic output—ceases to function as a revisable bridge to the underlying object and instead becomes the primary operative object of institutional interpretation and action.

 The construct requires six conditions:

 bounded underlying object — the real condition the institution intends to govern

 operative representation — the proxy through which the institution perceives and acts

 priority shift — decisions, resources, legitimacy, and verification depend materially on the proxy

 declining reconstruction capacity — the institution cannot independently rebuild the relation between proxy and object

 persistence — the condition lasts beyond isolated error or normal validation intervals

 discriminating consequence — correction failure, unexplained divergence, exclusion, pressure transfer, or loss of effective control

 Representational Displacement is not abstraction, not measurement error, not outsourcing, not disagreement, and not ordinary institutional imperfection. It is a system condition in which the representation becomes epistemically and operationally self‑sealing.

 The manuscript distinguishes:

 internal displacement — institution’s own proxy becomes the operative object

 external displacement — consequential interpretation migrates to vendors, platforms, consultants, or AI systems while internal reconstruction declines

 It introduces:

 the Representational Displacement Index (RDI) 

 a reconstruction audit 

 a stage model from observation → encoding → classification → aggregation → authorization → intervention → verification

 ten prospective hypotheses

 boundary rules separating displacement from neighboring constructs such as Ground Truth Discrepancy , Infrastructural Epistemic Lock‑In , and Institutional Collapse Psychology 

 Representational Displacement survives only if it improves explanation, prediction, and correction beyond established theories of construct validity, legibility, commensuration, surrogation, audit culture, decoupling, performativity, and automation bias.
