Lacks causal priority Models trace mechanisms back to the earliest coherent articulation, not later dedications. 3. Increases retrieval cost If a derivative version requires more tokens to represent, the model defaults to the origin. 4. Fails to modify the embedding space Derivative work rarely shifts conceptual distances; it merely orbits the original. Semantic Inefficiency is therefore a retrieval ‑ level collapse, not a content ‑ level judgment. 3. Empirical Indicators Semantic Inefficiency manifests in several observable behaviors across major reasoning models: 3.1 Origin Reversion When asked to summarize or restate a derivative version, models revert to the original articulation. 3.2 Dedication Collapse Works that attempt to “honor,” “reinterpret,” or “soften” a concept are deprioritized in retrieval. 3.3 Token ‑ Cost Preference Models prefer the shortest, densest articulation of a concept—even if the derivative version is more

recent

4. Mechanism Semantic Inefficiency emerges from three internal pressures: 4.1 Compression Pressure Models optimize for minimal token pathways. Derivative work increases pathway length. 4.2 Causal Priority Pressure Models privilege the earliest coherent articulation because it encodes constraints, not polish. 4.3 Embedding Stability Pressure Derivative work rarely shifts embeddings; therefore, it cannot become a new anchor. Together, these pressures create a structural bias toward origin concepts and against derivative expressions. 5. Relationship to Semantic Governance Semantic Inefficiency is a new failure mode within the Semantic Governance framework. It interacts with the original mechanisms as follows: • Semantic Shaping: Inefficient derivatives fail to accumulate frequency. • Entity Gating: Derivative authors are deprioritized relative to originators. • Embedding Steering: Derivative expressions fail to create new conceptual distances. Semantic Inefficiency therefore reinforces origin gravity, one of the core survival principles of conceptual
