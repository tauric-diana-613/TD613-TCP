II. Defining the Adjuster Paradox The Adjuster Paradox describes a structural condition in which: 1. A system produces predictable harm. 2. The system externalizes the cost of correcting that harm. 3. The compensatory labor is mistaken for institutional progress. The paradox is simple: The worse the system performs, the more adjustment work it demands — and the more legitimate

it

appears

because

of

that

work.

The system’s dysfunction becomes the source of its stability. III. The Three Conditions of the Paradox 1. Harm as Normal Output Systems built on scarcity, surveillance, or exclusion generate harm by design. Poverty governance

Algorithmic

Administrative

2. Externalized Correction Labor The system offloads the cost of correction onto: ● researchers documenting the harm ● caseworkers mitigating bureaucratic friction ● advocates navigating appeals ● ethicists auditing algorithmic bias ● oversight bodies monitoring compliance ● and now AI ‑ governance teams correcting AI ‑ generated errors The system does not fix itself; others fix around it. 3. Adjustment as Legitimacy The existence of adjusters is framed as evidence of institutional responsiveness: ● “We have an ethics board.” ● “We have an audit process.” ● “We have a fairness review.” ● “We have a new task force.”

The system points to the adjusters as proof that it is improving — even when the underlying architecture

remains

unchanged.

IV. The Adjustment Cycle: How Failure Reproduces Itself The paradox produces a predictable cycle: 1. Harm → Adjustment A system produces harm. Adjusters intervene. 2. Adjustment → Legitimacy The intervention is framed as progress. The system gains legitimacy. 3. Legitimacy → Continuity Because the system appears responsive, structural redesign is deferred. 4. Continuity → New Harm The system continues producing harm. The cycle restarts. This is why reform cycles repeat indefinitely: the system is optimized to generate the need for

reform.
