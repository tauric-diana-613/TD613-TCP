4. Core Constructs 4.1 Governance Altitude (GA) Hierarchical distance between behavioural observation and decision authority.

Levels: ● Level 0: Lived experience ● Level 1: Frontline documentation ● Level 2: Supervisory interpretation ● Level 3: Administrative classiﬁcation ● Level 4: Executive governance

4.2 Ground-Truth Discrepancy Index (GTDI) \text{GTDI} = \frac{|F^{\prime} - I^{\prime}|}{F^{\prime} + \epsilon} Where: ● F' = standardized frontline-coded behavioural proxy ● I' = institutional interpretation proxy ● \epsilon = stability constant

4.3 Signal Compression Ratio (SCR) \text{SCR} = \frac{\text{Character Count}_{frontline}}{\text{Character Count}_{institution}}

4.4 Administrative Abstraction Index (AAI) \text{AAI} = \frac{\text{Administrative Tokens}}{\text{Contextual Tokens}}

4.5 Hypothesized Pathway \text{GA} \rightarrow \text{SCR} \rightarrow \text{AAI} \rightarrow \text{GTDI}

5. Structural Mechanisms ● abstraction compression ● throughput optimization ● liability-driven interpretation ● documentation distortion ● governance-layer distancing ● administrative signal ﬁltering ● institutional self-protective drift

Appendix A: SignalRupture Methods, Coding Instruments,

and

GTDI

Extraction

Protocol

A1. Overview of Measurement System The SignalRupture (SR) measurement system operationalizes Ground-Truth

Discrepancy

(GTDI)

as

a

structured

comparison

between:

● F ′ (Frontline Observational Proxy): closest available representation

of

behavioural

reality ● I ′ (Institutional Interpretation Proxy): formal administrative or coded

representation

of

the

same

case

episode

All measures are derived from a Case Episode Unit (CEU) consisting of

intake

documentation,

frontline

notes,

and

downstream

institutional

classiﬁcation

records.

A2. Case Episode Unit (CEU) Deﬁnition A CEU is valid if it contains all three components: 1. Frontline Record (F-source) ○ case worker notes ○ intake assessment ○ direct observation logs ○ client narrative transcription 2. Institutional Record (I-source) ○ coded diagnosis / classiﬁcation ○ eligibility determination

○ administrative summary ○ program assignment record 3. Outcome Variable (optional) ○ service engagement ○ escalation event ○ discharge outcome ○ system re-entry

A3. Coding Instrument I: Frontline Behavioural Encoding (F ′ )

Objective Convert unstructured frontline text into standardized behavioural feature

vectors.

Procedure Each CEU is coded across 6 dimensions:

Dimension Code Type Scale Behavioural stability ordinal 0–4 Environmental stressors ordinal 0–4

Functional capacity ordinal 0–4 Crisis intensity ordinal 0–4 Social support presence ordinal 0–4 Temporal volatility ordinal 0–4 F ′ Construction F ′ is computed as: ● vector aggregation of all six dimensions ● normalized to [0,1] Normalization rule:

F'

=

\frac{\sum_{i=1}^{6}

x_i}{24}

A4. Coding Instrument II: Institutional Interpretation Encoding

(I ′ )

Objective Extract institutional classiﬁcation from administrative records. Procedure

Each CEU institutional record is coded across:

Dimension Code Type Diagnostic category rigidity categorical → ordinal Eligibility strictness ordinal (0–4) Administrative severity ordinal (0–4) Program allocation intensity ordinal (0–4) Risk classiﬁcation level ordinal (0–4) I ′ Construction I' = \frac{\sum_{j=1}^{5} y_j}{20}

A5. GTDI Extraction Rule Ground-Truth Discrepancy Index is calculated per CEU: \text{GTDI} = \frac{|F' - I'|}{F' + \epsilon} Parameter Deﬁnition

● ε = 0.01 (stability constant) ● F ′ = normalized behavioural proxy ● I ′ = normalized institutional interpretation Edge Case Handling

Condition Rule F ′ = 0 set F ′ = ε to avoid undeﬁned ratio Missing I ′ CEU excluded or imputed via domain mean Multiple I ′ entries average across institutional codings A6. Signal Compression Ratio (SCR) Extraction Objective Measure structural reduction in narrative volume. \text{SCR} = \frac{T_F}{T_I} Where: ● T_F = token count of frontline record

● T_I = token count of institutional record Tokenization Rules ● Use whitespace + punctuation tokenization ● Exclude stopword removal (to preserve administrative structure signals) ● Maintain raw linguistic density

A7. Administrative Abstraction Index (AAI) Extraction Objective Measure shift from contextual to procedural language. \text{AAI} = \frac{P_T}{C_T} Where: ● P_T = procedural tokens ● C_T = contextual tokens

A7.1 Procedural Token Dictionary Include: ● eligibility ● assessment ● criteria ● compliant ● protocol

● intake ● discharge ● authorization ● category ● classiﬁcation ● risk level

A7.2 Contextual Token Dictionary Include: ● observed ● reported ● described ● experiencing ● appears ● states ● indicates ● environment ● behavior ● narrative

A8. Governance Altitude (GA) Coding Instrument GA is coded as an ordinal structural position variable:

Level Role Type Score 0 Client / lived experience 0 1 Frontline worker 1 2 Supervisor 2 3 Administrative analyst 3 4 Executive / policy authority 4 Assignment Rule Each record is assigned GA based on author of interpretation , not subject.

A9. Reliability Protocol A9.1 Cross-Coder Procedure ● minimum 2 independent coders per CEU

● blind coding of F ′ and I ′ separately ● reconciliation only after scoring A9.2 Agreement Metrics ● Cohen’s κ (categorical dimensions) ● ICC (continuous indices: F ′ , I ′ , GTDI) A9.3 Acceptability Thresholds ● κ ≥ 0.70 = acceptable ● ICC ≥ 0.75 = acceptable ● below threshold → recoding required

A10. Dataset Construction Workﬂow 1. Extract CEUs from institutional systems 2. Split into F-source and I-source corpora 3. Apply coding instruments (A3, A4, A7) 4. Compute GTDI, SCR, AAI 5. Assign GA level 6. Aggregate into panel dataset Final dataset structure: | CEU | F ′ | I ′ | GTDI | SCR | AAI | GA | Outcome |

A11. Analytical Readiness Rules Dataset is valid for analysis only if:

● ≥ 80% of CEUs have complete F ′ and I ′ pairs ● inter-coder reliability thresholds met ● tokenization consistency veriﬁed across domains ● GA distribution spans at least 3 levels

A12. Primary Statistical Models (Operational Use) ● Multilevel regression (CEU nested in institution) ● Structural equation modeling (GA → SCR → AAI → GTDI) ● Cross-lagged panel models (time-series CEUs) ● Mediation analysis (SCR and AAI pathways)

A13. Summary of Extraction Logic SignalRupture operationalizes institutional drift as: 1. Behavioural encoding (F ′ ) 2. Institutional encoding (I ′ ) 3. Compression measurement (SCR) 4. Linguistic abstraction measurement (AAI) 5. Hierarchical position mapping (GA) 6. Normalized divergence (GTDI) Together, these constitute a complete measurement pipeline for institutional

interpretive

drift.
