## Result

The eight rupture routes are not a one-to-one public renaming of the nine formal layers.

Observed pattern:

```text
some routes ~= formal-layer-local neighborhoods
other routes = cross-layer traversals
```

The source therefore supports two distinct navigation surfaces:

```text
CANON MAP
  question answered: where does a work live in the formal field architecture?

START HERE
  question answered: from which lived / diagnostic rupture should a reader enter the field?
```

Archive terminology only:

```text
FORMAL_TOPOLOGICAL_INDEX
vs
EXPERIENTIAL_DIAGNOSTIC_INDEX
```

or equivalently:

```text
ALTERNATE_BASIS_NAVIGATION_CANDIDATE
```

`basis` is not an SR source term here and should not be read as a mathematical theorem.

## Why this matters to the original Magic-Eye assignment

A reader of only the Canon Map sees a hierarchical field taxonomy.
A reader of only START HERE sees an onboarding guide.

The aggregate reveals that the same work graph is traversable through at least two non-equivalent indexing logics:

```text
formal architecture
and
reader-condition / rupture archetype
```

This is direct evidence that SR's human-facing navigation is multi-coordinate rather than a single table of contents.
