## 6. Consequence for routing grammar

The same source object contains both:

```text

```

Therefore:

```text

```

Status vocabulary may encode an internal / editorial / canonical lifecycle state distinct from first public deposition.

This is a critical hostile control for all future-resolving-object analysis.
