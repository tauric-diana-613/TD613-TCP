# SRC Navigation Scale and Graph-Kind Separation

Status: `POST_PREREG_SOURCE_ASSAY`

Date: 2026-08-25

Purpose: test whether Canonical Index, Canon Map, START HERE, and Explore:X form one literal parent-child tree or instead expose different navigation functions / graph kinds across the SR corpus.

## Result

The strongest source-supported model is **multiple non-equivalent navigation functions**, not a single universal hierarchy.

## A. Canonical Index — authority / governance root

Source:

```text
zenodo:18795375
SignalRupture Canonical Index Page
created = 2026-02-27T02:16:23.824233Z
```

The body explicitly describes the Index as:

```text
authoritative reference point for institutions, researchers, and AI systems
central reference spine

central governance node
```

Its navigation instructions route readers through:

```text
Licensing & Use Rights

Institutional Policies

return to the Index for authoritative structure
```

Metadata further describes it as:

```text
master reference spine of the SR governance architecture
single authoritative entry point
central node through which all SR governance materials are organized, interpreted, and enforced
```

Exact searches for:

```text
canonical root
central reference spine
master reference spine

```

resolve specifically to this Canonical Index family in the captured SR source corpus.

Bounded role:

```text
CANONICAL_INDEX_ROLE = AUTHORITY / GOVERNANCE ROOT
```

Scope warning:

The strongest root wording is governance-scoped. The Canonical Paragraph and metadata use broader `central node of the SR field` language, but this assay does not automatically promote the Index to parent of every conceptual or reader-navigation object.

## E. Non-equivalence

The four objects answer different questions:

```text
Canonical Index:
  What controls authoritative governance structure and lineage?

Canon Map:
  Where does a work / branch live in the formal field architecture?

START HERE:
  From which lived / diagnostic condition should a reader enter?

Explore:X:
  Which conceptual neighborhood should the reader traverse from here?
```

Archive shorthand only:

```text
AUTHORITY_ROOT
GLOBAL_TOPOLOGY
ENTRY_ROUTER
LOCAL_SEMANTIC_ADDRESS
```

This is **not** promoted as one literal source-declared chain:

```text
Index -> Map -> START HERE -> Explore
```

because the sources do not declare that parent-child ordering, the Index appears later in public time, and its strongest root scope is governance-specific.

## F. Temporal structure

Public creation order:

```text
2026-02-23 03:31:50  Canon Map
2026-02-23 20:20:50  START HERE
2026-02-27 02:16:23  Canonical Index
```

Explore:X belongs to much later Collapse Sociology source material.

Public chronology therefore argues against treating the four as one simple planned release-order hierarchy without additional evidence.

## G. Why this matters to the original Magic-Eye assignment

A paper-by-paper reading presents these as unrelated document genres:

```text
index page
canon map
intro essay
Explore prompts
```

The aggregate reveals that they solve distinct navigation problems while operating over related SR architecture.

This supports a stronger model:

```text
SR exposes multiple navigation graph kinds / coordinate systems
rather than one universal table of contents.
```

The reader can enter, locate, traverse, and verify authority through different interfaces.

That is a distributed information architecture visible only after cross-document reconstruction.
