## 1. Canonical Paragraph — node compression

`The Meta-Architecture of the SR Canon` (`zenodo:18732891`) explicitly defines each essay-node as carrying a:

```text
canonical paragraph (the compression layer)
```

The Canonical Paragraph is therefore treated as compressed node content / canonical identity payload.

Classification:

```text
CANONICAL_PARAGRAPH_ROLE = NODE_COMPRESSION
SOURCE_STATUS = DECLARED
```

The presence of many `Canonical Paragraph` sections across the corpus is compatible with a standardized node-payload convention.

## 2. Reference Paragraph — graph placement / lineage context

Exact `Reference Paragraph` terminology is rare relative to Canonical Paragraph.

Distinct captured hosts include:

- `zenodo:18343915` — *Semantic Inefficiency*
- `zenodo:18364461` — *Cross-Surface Recurrence*
- `zenodo:18248959` — *Social Media and the Hive Mind*
- `zenodo:18176137` — *Exact-Match Governance*

Observed function is stable despite label variation (`Reference Paragraph`, `Canonical Reference Paragraph`, `Canonical SR-Canon Reference Paragraph`).

### Semantic Inefficiency

The reference paragraph:

```text
extends the SR canon
names the frameworks it joins
identifies the mechanism contributed by the current work
situates that mechanism in the broader environment
states the canon claim reinforced by the addition
```

### Cross-Surface Recurrence

The reference paragraph:

```text
situates the essay within the established canon
names predecessor works
places the essay in an infrastructural series
assigns it a role as an initiating mechanism in a larger architecture
```

### Social Media and the Hive Mind

The canonical reference paragraph:

```text
names foundational works
calls them the architectural backbone
states that the present essay extends that lineage
identifies the specific application domain
```

### Exact-Match Governance

The canonical reference paragraph:

```text
states how the essay should be cited
identifies the lineage it extends
states the new mechanism contributed
identifies future empirical research for which it supplies conceptual foundation
```

Bounded classification:

```text
REFERENCE_PARAGRAPH_ROLE = GRAPH_PLACEMENT / LINEAGE_CONTEXT
REFERENCE_PARAGRAPH_IS_NODE_COMPRESSION = false
```

Archive shorthand only:

```text
Canonical Paragraph -> WHAT THIS NODE COMPRESSES
Reference Paragraph -> WHERE THIS NODE SITS / WHAT IT EXTENDS
```

The source does not declare this comparison as a formal theorem; the role distinction is reconstructed from source behavior plus the Meta-Architecture's explicit compression definition.

## 8. Current routing-object grammar

Archive reconstruction:

```text
SIGNATURE PHRASE
  semantic / cultural anchor and reader orientation

CANONICAL PARAGRAPH
  compressed node content

REFERENCE PARAGRAPH
  node placement / lineage context

EXPLORE:X
  semantic navigation address

COMPANION / FORTHCOMING EDGE
  forward-declared work-to-work relation

BRIDGE SENTENCE
  local payload specifying what transfers across that edge

CANON MAP
  explicit topology / role placement

SURFACE TRANSLATION
  projection rule for heterogeneous destination surfaces
```

These objects are compatible and non-equivalent.
