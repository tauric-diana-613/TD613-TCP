# Authority Registry

Authority is time-indexed and five-dimensional:

- `G` — genealogically retained;
- `C` — canonically authoritative;
- `E` — empirical authority;
- `F` — field-defining authority;
- `K` — controlling formulation.

No axis implies another. Class-level policy never silently expands into individual work status. `legacy-membership-candidates.jsonl` therefore records date-criterion matches without asserting that any listed work is individually classified Legacy.
