# Claim and Evidence Registry

Claim events preserve the source's wording, a controlled archive status, its scope, evidence taxonomy, measurements, competing explanations, falsifiers, counterexamples, and prior event links.

Evidence-taxonomy namespaces remain source-specific. SIS `E0–E5`, CEIDF `E1/E2/S1/S2`, and any future IGF ladder must not be normalized into one scale without an explicit mapping receipt. The SR-native label `theorem` never supplies proof or empirical authority by itself.
