# Canon Map Snapshots

Every Canon Map is an immutable author self-model `C_t`, not the archive's truth and not a mutable “latest map.” February, June, and August snapshots remain separately queryable.

Future crosswalks may record persistence, rename, split, merge, promotion, disappearance, and unresolved correspondence. They may not overwrite an earlier snapshot or leak hindsight into a contemporaneous `G_t` reconstruction.
