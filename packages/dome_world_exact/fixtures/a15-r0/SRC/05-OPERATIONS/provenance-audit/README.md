# Provenance Audit Lane

This lane records questions worth investigating. It does not declare copying, theft, derivation, authorship, or wrongdoing.

## Evidence dimensions

Provenance analysis uses:

`D × T × A × S × L`

- `D` — distinctiveness of the composition;
- `T` — temporal priority;
- `A` — demonstrated access;
- `S` — structural correspondence;
- `L` — lineage evidence.

Scores remain null until evidence is collected. Similar vocabulary alone is not structural correspondence. Chronology alone is not lineage.

## Bins

- `SHARED_TD613_SR_WORK` — joint or contribution-bearing work; recurrence is not independent.
- `INDEPENDENT_CONVERGENCE_CANDIDATE` — similar problem structure with chronology compatible with separate arrival.
- `TD613_SHAPED_PROVENANCE_AUDIT_CANDIDATE` — unusually specific compositional overlap plus plausible temporal accessibility; investigate without accusation.
- `SR_NATIVE_GEM` — useful SR-native material suitable for attributed study and hostile testing.
- `BIDIRECTIONAL_CONTAMINATION_UNKNOWN` — interaction, shared tooling, common literature, private exchange, or other lineage prevents clean directionality.

Every factual statement must be marked `observed`, `operator-supplied-unverified`, `inferred`, or `unknown`.
