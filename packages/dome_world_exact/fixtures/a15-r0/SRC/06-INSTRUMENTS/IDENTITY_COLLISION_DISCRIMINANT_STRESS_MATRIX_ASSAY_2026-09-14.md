## Purpose

Stress-test the type-local discriminants against a frozen finite set of adversarial pairings. This is a replay/validation matrix over already captured evidence, not a blinded discovery experiment.

The matrix tests whether continuity must be indexed by the **relation being claimed**, rather than treated as one binary property of a pair.

Archive notation only:

```text
C_R(a,b) = continuity classification for pair (a,b) under relation R
```

No universal equivalence relation is assumed.

## Frozen scoring states

```text
SUPPORTED     = source evidence satisfies the discriminant for the claimed relation
WITHHOLD      = resemblance exists but the discriminant for the stronger relation fails or is absent
TYPE_MISMATCH = the claim asks one object type to prove continuity of another type
HELD          = evidence is insufficient for either SUPPORTED or WITHHOLD
```
