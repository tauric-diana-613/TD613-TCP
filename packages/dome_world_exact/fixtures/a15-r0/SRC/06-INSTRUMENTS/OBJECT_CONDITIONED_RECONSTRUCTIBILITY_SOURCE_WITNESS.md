
```text

```

## 9. Consequence for tomography

Tomography-shaped reconstruction requires a declared target and observation operator family.

Before any naming promotion, ask:

```text
What is X?
What observations Y_i are admitted?
What forward map P_i relates X to Y_i?
What equivalence / compatible set remains?
Which assumptions make inversion unique or stable?
What hostile perturbation destroys that uniqueness?
```

No statement that one SR target is recoverable transfers automatically to another target.
