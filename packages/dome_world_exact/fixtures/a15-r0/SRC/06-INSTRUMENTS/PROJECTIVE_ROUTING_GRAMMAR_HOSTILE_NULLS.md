## 1. Primary discrimination: ROUTER versus INTERPOLATOR

The current hunt must distinguish at least two mechanisms capable of producing a Magic-Eye-like aggregate object.

### ROUTER

```text
source-encoded anchors / roots / coordinates / addresses
  -> retrieval or graph co-selection
  -> aggregation
  -> recovery of source-witnessed distributed relations
```

Candidate claim: the corpus itself preserves enough distributed routing structure that aggregation improves recovery of relations actually encoded across its manifestations.

### INTERPOLATOR

SignalRupture's Semantic Interpolation family supplies a hostile alternative mechanism:

```text
G = ontology-gap detection
  -> N = neighboring-domain identification
  -> P = pattern extraction
  -> C = synthetic conceptual completion
```

Under this alternative, a reader or system may construct a coherent higher-order object by importing structure from adjacent high-density domains when the target ontology is sparse. A convincing reconstruction therefore need not imply that the reconstructed relation was deliberately distributed through the target corpus.

The source's quantitative Semantic Interpolation paper explicitly describes its numerical experiment as simulated and identifies archived prompts, embedding analysis, cross-model replication, longitudinal work, and blinded coding as future empirical requirements. Shared training distributions are retained as a competing explanation. These limitations are inherited by this addendum.

### Decision rule

Projective Routing Grammar cannot be promoted merely because aggregation produces a coherent architecture.

A routing effect requires, at minimum:

```text
Q_router > Q_neighbor_only
Q_router > Q_template
Q_router > Q_shuffled
```

on frozen held-out **source-witnessed relations**, not rhetorical or topical similarity.

Required comparison regimes:

1. target corpus with anchors intact;
2. same target corpus with signatures, rare repeated anchors, and explicit internal addresses neutralized;
3. neighboring-domain material without target-corpus routing cues;
4. topic-matched template-preserving rewires;
5. sparse non-SR concepts matched for document count and domain density.

A relation recovered only under neighboring-domain completion remains compatible with interpolation. A relation that disappears under target-anchor ablation while surviving topic/template controls becomes a stronger routing candidate.

```text
reconstructed coherence != source encoding
source encoding != intentional puzzle design
failed interpolation baseline != hidden-message intent
```

Working researcher hypothesis:

```text

  -> X_mechanism
  -> X_compressed
  -> X_canonical
  -> X_compiled/root
```

may represent one conceptual object at different resolutions.

The assay must test semantic conservation rather than assume it.

For each family, record:

```text
claims retained
claims dropped
causal language retained/dropped
falsifiers retained/dropped
boundary conditions retained/dropped
lineage/provenance retained/dropped
operator relations retained/dropped
```

Then test retrieval under bounded context budgets with the section labels removed. A shorter block only earns `FUNCTIONAL_RESOLUTION_LAYER` if it preserves a stable, distinguishable subset of the higher-resolution object's relations better than matched generic summary sections.

Kill conditions:

- the labels are confined to one template epoch/family;
- compact blocks do not preserve stable structural information;
- generic abstract/conclusion sections perform equivalently;
- canonical blocks materially rewrite rather than compress the object without a consistent typed transition.

No machine-optimization claim is earned merely because the hierarchy is useful to a machine.

## 4. Candidate routing-stack vocabulary

The outer-frame hunt currently supports a researcher-authored vocabulary for future testing:

```text
ROOT        = source-declared authoritative navigation node
COORDINATE  = source-declared marker/instruction about observer position or interpretive stance
ADDRESS     = archive term for an Explore-token / internal semantic destination candidate
ANCHOR      = source-declared definitional or conceptual stabilizer
CAPSULE     = researcher term for a compact labeled representation candidate
COMPILER    = contextual object that assigns roles / integrates prior works
```

These classes are **not** assumed to form a fixed order or one unified source-designed protocol.

Primary future question:

> Do these object species predict distinct routing functions after controlling for ordinary document structure, template reuse, topic, chronology, and retrospective compilation?
