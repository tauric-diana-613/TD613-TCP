## 3. Machine conformance remains an implementation problem

The Governance Stack says the machine-legible layer remains limited in implementability and proposes a future deployable conformance standard containing:

```text
vocabulary identifiers
source ranking
expected outputs
ambiguity handling
correction behavior
prohibited transformations
retrieval examples
conformance grades
```

It separately requires a threat model for:

```text
prompt injection
poisoned retrieval
stale indexes
source impersonation
conflicting mirrors
model compression
unlicensed fine-tuning
accidental genericization
```

This is source evidence that machine-facing field integrity is treated as an engineering / conformance problem, not as automatic control over arbitrary external systems.
