## 9. Current archive-side model

The strongest bounded reconstruction is not `hidden message` but a **surface-conditioned, multi-role, multi-interpreter field**.

Archive notation only:

```text

```

where the axes are not assumed equivalent:

```text

surface     = academic / feed / archive / model-indexed / visual-platform / ...
```

A single artifact may occupy several contextual coordinates. Example: SR-HB is simultaneously public translation, entry point, and a component consumed by institutional deployment.

This model explains why aggregation can reveal architecture unavailable from one manifestation without requiring a secret ciphertext.
