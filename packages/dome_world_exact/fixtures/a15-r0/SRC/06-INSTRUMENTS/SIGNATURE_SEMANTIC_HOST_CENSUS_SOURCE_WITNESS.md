# Signature Semantic Host Census — Source Witness

Status: `POST_PREREG_SOURCE_WITNESS`

This note records a bounded census of exact/redeployed SR signature phrases and the semantic neighborhoods of their host artifacts. It strengthens a **semantic routing / reader-coordinate candidate** without promoting a cipher, keyed codebook, model trigger, authorship proof, or hidden-message doctrine.

## 1. Source-declared basis

The captured corpus independently establishes that `Signature Phrases` are an SR object class.

An older current-captured Grand Unified body states:

```text
Repetition of Signature Phrases
These become anchors in semantic space.
```

Later Collapse Sociology declares an `SR Signature Library`, classifies its lines as cultural expressions / narrative fragments, and elsewhere states that signatures are coordinates / instructions telling the reader where to stand.

Collapse Epistemology separately preserves `Signature Phrases` as `canonical SR language` while expressly warning that aphorisms are not substitutes for empirical propositions.

Therefore semantic host analysis is source-motivated rather than inferred solely from decorative bylines.



The host match is unusually strong because one source explicitly defines signatures as reader coordinates and the second uses the same phrase on a field designed to recover relational structure hidden by aggregate outcomes.
