## 4. Core question

Let `Q(S)` be the quality of relation recovery for source subset `S` under a fixed scoring protocol.

The high-value positive condition is not merely:

```text
Q(F+N+G) > Q(F)
```

because more text trivially carries more information.

A genuine three-stratum gain requires at least one frozen target relation or relation-family whose recovery satisfies:

```text
Q(F+N+G) > max(
  Q(F+N),
  Q(F+G),
  Q(N+G)
)
```

under matched context / token budget or another preregistered normalization.

Stronger condition:

```text
there exists target relation r
such that every single / pairwise subset leaves r unresolved,
but the triple resolves r from mutually complementary evidence
```

This is `TRIPLE_OVERLAY_GAIN`, not supermoire.

## 5. Pair-emergence control

Before testing triple emergence, evaluate pairwise emergence explicitly.

For pair `(A,B)`:

```text
PAIR_GAIN(A,B) = Q(A+B) - max(Q(A), Q(B))
```

A positive pair gain requires frozen evidence that the relation belongs to the interaction / complementarity of the two strata rather than simple duplicated prose.

This gives a bounded abstract control adjacent to the Information Dome's pair-emergent Moire pedagogy without importing Moire physics.

## 6. Strong hostile nulls

### 6.1 More-text null

Triple overlay may win merely because it contains more tokens.

Control by:

```text
matched token budget
matched excerpt count
matched number of source objects
```

### 6.2 Topic-density null

Replace one stratum with topic-matched SR material that shares vocabulary but lacks the candidate relation.

### 6.3 Template null

Preserve headings / document architecture while shuffling substantive paragraphs within allowed source boundaries.

### 6.4 Semantic Interpolation null

Supply neighboring high-density source families while withholding the target SR anchors. If the target relation is still reconstructed at the same rate, the result may be synthetic completion rather than encoded cross-stratum complementarity.

### 6.5 Label leakage null

Remove explicit labels such as:

```text
partial projection
structural observer
simulation narrative
canonical paragraph
compression layer
```

and test whether the relation remains recoverable from operational structure.

### 6.6 Chronology leakage null

Remove dates / public order where temporal information is not part of the target relation.
