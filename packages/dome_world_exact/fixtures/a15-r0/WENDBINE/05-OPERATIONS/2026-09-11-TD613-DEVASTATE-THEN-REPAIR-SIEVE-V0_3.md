## Source-bound attacks

### FADT / finite admissibility descent

Pawlak-style rough sets already use lower/upper approximations and a boundary region `upper - lower`. Standard quotient factorization already supplies the exact descent criterion. The remaining TD613 cardinality identity

```text
|A \ I| + |U \ A| = |U \ I| + |A \ U| + |I \ A|
```

for `I subset U` is an elementary disjoint-set decomposition, not a theorem family requiring a novelty claim. The minimum `|U\I|` occurs exactly for `I subset A subset U`.

Sources:
- https://link.springer.com/article/10.1007/s11047-018-9700-3
- https://www2.cs.uregina.ca/~yyao/PAPERS/book_review.pdf

**Devastation:** theorem-shaped novelty credit is retired completely.  
**Repair:** scientific-facing name becomes **Finite Quotient Admissibility Audit (FQAA)**. `FADT` remains a legacy/internal alias only.

### V/C/P/L temporal non-retroactivity

Control theory already separates state observability from parameter/model identifiability. Temporal-epistemic logic has treated knowledge as time-indexed for decades; future knowledge does not automatically imply earlier knowledge absent a strong `no learning` assumption.

Sources:
- https://pmc.ncbi.nlm.nih.gov/articles/PMC6685009/
- https://plato.stanford.edu/archives/sum2026/entries/phil-multimodallogic/
- https://epubs.siam.org/doi/10.1137/S0097539797320906

**Devastation:** `later reconstruction != earlier possession` gets no novelty credit as a general epistemic principle.  
**Repair:** retain it as a **forensic temporal-accounting rule** inside a four-coordinate **forensic evidence-state vector**:

```text
V = trace visibility / measurement availability
C = custody / provenance recoverability
P = process / model identifiability
L = state observability / latent-state reconstructibility
```

### AIA

Secure multi-execution, observation functions, and decentralized information-flow control already provide principal/receiver-indexed observations, per-principal policies, authority relations, controlled declassification, and output-channel restrictions.

Sources:
- https://researchportal.vub.be/en/publications/noninterference-through-secure-multi-execution
- https://www.cs.cornell.edu/andru/papers/iflow-sosp97/paper.html
- https://www.cs.cornell.edu/andru/papers/sp98/paper.html

**Devastation:** the bare architecture of receiver-specific policy-governed views with authority is not novel.  
**Repair:** scientific-facing alias remains **receiver-indexed policy-governed view architecture**. `anisotropic` is reserved for modules with a formally defined directional operator/permeability relation.

### PRCS-A

Abstract noninterference explicitly parameterizes observation/protection/semantics, while knowledge-based security policies can dynamically suppress query answers based on the information a result would reveal. Selective prediction supplies abstention/reject behavior.

Sources:
- https://arxiv.org/abs/1309.5131
- https://journals.sagepub.com/doi/10.3233/JCS-130469
- https://aclanthology.org/2021.acl-long.84/

**Devastation:** no novelty credit is assigned to the individual stages or to the general idea of policy-mediated selective observation. No exact conventional source was located for the precise TD613 five-stage ordering, so that ordering is **not killed and not promoted**.

**Repair:** preferred description: **policy-conditioned coarsening, selective release, and registration pipeline**. The research target becomes whether the explicit ordering

```text
capacity -> coarsening/projection -> policy/admissibility -> naming -> registered event
```

has a formal consequence beyond bookkeeping.

### Holonomy Loom governance stack

UCON already unifies authorization, obligations, conditions, ongoing control, immediate revocation, and mutable attributes. Provenance-aware access-control research already uses dependency-path provenance as an authorization basis. Proof-carrying authorization and event sourcing cover proof/replay components.

Sources:
- https://doi.org/10.1145/984334.984339
- https://www.usenix.org/conference/tapp12/workshop-program/presentation/nguyen
- https://www.cs.princeton.edu/research/techreps/337

**Devastation:** broad governance-architecture novelty for Loom is rejected.  
**Repair:** describe the governance layer as a **provenance-aware continuous usage-control and revalidation workflow**. Reserve **holonomy** only for the separately scoped discrete transport operator where a based loop induces a nonidentity fibre automorphism.

### Safe Harbor / Right of Resignation

Research ethics already protects withdrawal and dynamic-consent work studies revocation propagation. Separately, succession planning and bus-factor literature explicitly treat continuity after a key person leaves as a knowledge-transfer/resilience problem.

Sources:
- https://pmc.ncbi.nlm.nih.gov/articles/PMC13272879/
- https://www.usgs.gov/human-capital/succession-planning-desk-guide-0
- https://arxiv.org/abs/2202.01523

**Devastation:** the general criterion “the work remains useful after the originator leaves” is not novel.  
**Repair:** retain it as the TD613 ethical acceptance test **custodian-independent handoff**: a handoff is not complete if useful operation still requires continued participation by the departing custodian. This is a project-specific governance rule, not a new field.
