
All five edges can be drawn with the same glyph `->`, but they are not one operator family.

Therefore the old full-chain superset notation cannot be inferred from arrow adjacency.

## 2. Stage-collapse hostile control

For a finite deterministic synthetic fixture, the full chain

```text
K -> P -> A -> N -> E
```

is compared with adjacent composite stages such as `(P o K) -> A -> N -> E`.

By construction, exact functional composition preserves terminal behavior. Across the declared finite input set, the full and collapsed forms are terminally identical. Therefore terminal output alone cannot justify the ontological independence of `K` and `P`.

The relevant question is diagnostic rather than ceremonial: what is lost when the stages are collapsed?

## 3. Terminal-equivalent failure worlds

Two worlds are constructed with the same terminal `NO_EVENT` result:

- **EMPTY_UPSTREAM:** no candidate survives the upstream selection stage;
- **SUPPRESSED_DOWNSTREAM:** a candidate survives upstream but is rejected at the release/admissibility stage.

Terminal observation alone cannot distinguish them. A stage-local witness (`candidate_count_after_selection`) does.

This yields the bounded result:

```text
TERMINAL_EQUIVALENCE != DIAGNOSTIC_EQUIVALENCE
```

A decomposition may therefore earn practical value when intermediate observations or interventions permit fault localization even if a collapsed composite predicts terminal outputs equally well.

## 4. Verdict

The same arrow glyph provides only a directed graph skeleton. Relation semantics require typed edges, domain/codomain declarations, and where scientifically relevant, stage-local witnesses or interventions.

PRCS-A / Eclipse–Omega receives no novelty credit from naming a sequence of stages. What survives is a falsifiable decomposition criterion:

> retain a stage boundary only when it contributes type safety, independent intervention, intermediate observability, held-out prediction, diagnostic localization, or a formal invariant not preserved by collapse.

Otherwise compose it away.
