> retain a stage boundary only when it contributes type safety, independent intervention, intermediate observability, held-out prediction/consequence, diagnostic localization, or a formal invariant not preserved by collapse.

`classifyTypedEpistemicDeficit` returns the deficit class, disposition, criterion, and reason. `auditTypedEpistemicDeficit` calls that classifier and wraps the result with provenance, policy metadata, input echo, Pedagogue cueing, replay-state labels, and governance non-authorities.

```text

RETAIN_AS_AUDIT_RECEIPT_BOUNDARY
```

## 3. Boundary B — singular-value posture -> typed deficit audit

`singularValuePosture2` measures the operator geometry. `auditTypedEpistemicDeficit` applies declared thresholds and policy semantics to those measurements.

The hostile intervention holds the operator posture fixed at:

```text

```

while changing only the declared `sigma_min_floor` from `0.25` to `1.01`.

The first audit yields:

```text

```

The second yields:

```text

```

The measured operator did not change. The declared audit threshold did.

Therefore the measurement/policy boundary earns independent intervention, intermediate observability, and diagnostic localization. Collapsing the two without preserving the intermediate posture would erase whether a changed disposition arose from the operator or from the threshold policy.

```text
FIXED_OPERATOR_POSTURE + THRESHOLD_INTERVENTION_CAN_CHANGE_DISPOSITION
```

Verdict: **RETAIN_BOUNDED_STAGE_BOUNDARY**.

## 5. Boundary D — question selection -> held-out consequence audit

The existing replay-envelope consequence assay already supplies the decisive hostile control.

Near a bounded selection boundary, the selected question flips while each candidate's held-out consequence surface remains locally smooth. The held-out functionals also produce mixed winners, and the held-out consequences were not used to choose the question.

That means selection and validation answer different questions.

```text
QUESTION_SELECTION != HELD_OUT_VALIDATION
POLICY_BOUNDARY != PERFORMANCE_CLIFF
```

Collapsing the two would silently promote one local selection criterion into a universal downstream quality claim.

Verdict: **RETAIN_BOUNDED_STAGE_BOUNDARY**.

## 6. Source-bound scorecard

Four candidate boundaries were examined:

```text
3 retain bounded scientific stage value
1 loses independent scientific-operator status
1 operational receipt boundary remains useful without operator promotion
```

The important result is selective rather than celebratory. The repository does not support the doctrine that every named boundary deserves ontological independence. It also does not support flattening every boundary into one composite.

The source-bound criterion is harsher and cleaner:

> preserve a boundary when an intervention, witness, failure localization, held-out consequence, type invariant, or formal distinction actually depends on it; otherwise compose it away or demote it to instrumentation.
