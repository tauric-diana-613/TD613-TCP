## 0. Research question

Can a bounded set of Wendbine and TD613/Loom concepts become mutually machine-legible in both directions while preserving source refs, retained differences, and authority non-transfer?

This is the first translation chamber in the repair route. It tests a crosswalk, not a merger.

```text
WENDBINE -> TD613/LOOM
TD613/LOOM -> WENDBINE
```

The assay does not permit `EXACT` as a relation class in v0.1. Admitted classes are:

```text
PARTIAL
ANALOGOUS
NON_EQUIVALENT
OPEN
```

That is deliberate. The experiment asks whether useful translation survives non-equivalence.
