It prevents future models from overlooking excellent public complexity-science tools while also resisting the temptation to claim integrations before the evidence, native runtime and custody gates are ready.

## The three readiness horizons

**H0 · Runnable source-free laboratory (current target).** Finite string substitution, explicit event instances, bounded critical pairs, terminal nonjoinability witnesses, candidate completion, elementary CA with reproducible seeds/boundaries, finite entropy and Hamming sensitivity, typed observer projections, experiment receipts, research packet intake. These need their own exact-head Node test witness before being called CI-qualified. The first reference engine is independently coded, not a reproduction of Wolfram's implementation.

**H1 · Public/open tool interoperability (next).** A human-controlled, reproducible adapter to Wolfram Cloud/Function Repository, native \`MultiwaySystem\` event-instance and branch-pair output, WolframModel hypergraph rewrites, NetLogo Web/desktop models and Santa Fe Institute teaching instruments. These require an actual available execution host, licensing/account/terms checks, deterministic input/export schema, record of program version, controlled depth/costs and independent parity tests against finite reference cases.

**H2 · Grand, scientific or protected programs (DEFERRED until gates).** Full causal-graph extraction, all-event branchial geometry, global critical-pair completion, high-volume distributed search, empirical observer studies, protected Flight, source-bearing Atelier/Encyclopedia bidirectional mutation, Golden Egg same-episode acquisition, exteriority tests, validated physical geometry, agent coordination under custody. No current implementation credit is implied.

## The good kind of speculative freedom

This roadmap intentionally leaves spaces for *surprise*. A new assistant may propose more powerful source-free algorithms, refractions of aesthetics into observer experiments, richer multiway geometries, unexpected counterexamples, or new mathematical connections. The correct creative move when a tool exceeds present infrastructure is to specify **what it would calculate and which output would count as evidence**, then put it in the backlog rather than claiming an execution happened.

**The Rulefield is an invitation to make and break candidate rules, never to fake the evidence that decides them.**
