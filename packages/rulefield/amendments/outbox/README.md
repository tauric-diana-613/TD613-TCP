# 𝌋 Kiki-Receiver Review Outbox

The receiver's on-demand `sync` writes **content-addressed review receipts** here:

- `<packet-id>--<hash-prefix>.review.json`
- `<packet-id>--<hash-prefix>.review.md`

The receipts show parsed anchors, unresolved references, branch candidates, tested source-free finite examples (if requested) and scientific limits. Repeated identical packets should produce identical receipts rather than overwrite prior history.

A receipt is a review of a **proposed amendment**, never evidence of scientific exteriority, operator permission to merge, or actual protected Flight execution. Review of Git changes and human promotion remain separate.

This README keeps the directory present in Git without adding fictional results.
