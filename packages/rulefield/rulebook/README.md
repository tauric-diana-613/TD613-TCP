# 𝌋 Rulefield Rulebook

Start with [LLM_QUICK_START.md](LLM_QUICK_START.md), then [source_locator.json](source_locator.json) and [../AGENTS.md](../AGENTS.md).

The guide is designed for an LLM dropped into a fresh research thread with a GitHub repository or ZIP, with or without cross-chat memory. It specifies the source families to locate, allowed retrieval methods, evidence classification, immutable-revision citation and conversion into source-free amendment proposals.

Next steps: [amendment receiver](../amendments/RECEIVER.md), [NKS lab](../lab/README.md), [capability roadmap](../ROADMAP.md). Keep the source artifact's original meaning and uncertainty.

A memory retrieval is a lead, not primary evidence. A public reference is a candidate tool, not a performed experiment.
