# 𝌋 Rulefield Gleaning Protocol — Source Discovery and Scientific Typing

**Receiver:** Antigravity, Amari, Work, Codex, or another authorized agent.  
**Default:** research archaeology and source-free proposal stage. **No automatic search of private accounts or local storage.** Tool access is limited to actually available authorized connectors.

## Input
- Human-authored \`HUMAN_RULEFIELD_SUBMISSION_REQUEST.md\`, operator expressions (one word, equation, paragraph, or arbitrary-length thought), or \`td613.rulefield.operator-field-seed/v1\`.
- Current \`data/rulefield.v1.json\` as immutable baseline for 596 rules, 88 crossings, and 70 historical priorities.
- The user-selected research scope, temporal window, and source permissions.

## Stages: EXTRACT → TYPE → TRACE → CHALLENGE → PROPOSE → DISCLOSE

**EXTRACT.** Preserve verbatim original expressions, sequence, punctuation, signs, author/source statement, and unknown referents. A working label should be academically recognizable and revisable. Retain alternative interpretations instead of generating the most sophisticated-sounding title.

**TYPE.** Distinguish at minimum: RULEFIELD (question/domain), RULE (formal local predicate), METHOD (assay), MODEL (defined states/transitions), CLAIM (empirical assertion), METAPHOR (interpretive apparatus), PERSON/REFERENT (potentially unresolved identity), PRODUCT/AFFORDANCE (design proposal), SOURCE (observed record), and AUTHORIZATION (actual human act). Do not treat NKS heuristics as universal theorems or reinterpret clinical language as a diagnosis.

**TRACE.** Use a declared source set and search budget; record source URL or repository ref with actual seen spans, times and access conditions. Search local/user library sources only when attached or actually authorized. Github/Library connector access cannot be manufactured by a ZIP. A memory recall is a lead. A file's name is not a witness to its contents.

**CHALLENGE.** Compare formalizations against competent information-matched alternatives and accepted theory. Distinguish exact lexical collision, plausible semantic overlap, irreducible ambiguity, contrary proposition and genuinely distinct domain. Classify an earlier rule as a possible *member* of a field, not as an equivalent field by default.

**PROPOSE.** Where a local rule could be defined, provide state type, initial condition, update semantics, variable units, scheduler, event provenance, observer projection, stopping conditions, falsifier and competent null. Where missing, stage an UNQUALIFIED_RULEFIELD rather than faking an executable theory.

**DISCLOSE.** Every output retains the original wording, working label and status; the evidence it actually retrieved; all hypotheses; all unresolved identities; the number of candidates examined; the actual computational result (if run); and a precise account of what would authorize adoption. The normal Rulefield amendment receiver is the downstream gateway for formal rule changes.

## Non-equivalence safeguards

\`RULEFIELD ≠ RULE\`; \`UNSEEN POSSIBILITY ≠ OBSERVED EMERGENCE\`; \`LEXICAL OVERLAP ≠ LOGICAL EQUIVALENCE\`; \`RESEARCH CITATION ≠ INDEPENDENT SOURCE AUTHENTICATION\`; \`MECHANISTIC ANALOGY ≠ PHYSICAL LAW\`; \`INTERFACE PLANNING ≠ COMPLETED UI\`; \`RESEARCH QUEUE ≠ EVIDENCE RANKING\`.

Preserve every unverified origin, and avoid reifying speculative identities, hidden agents, or unsupported psychological/social claims. Give social and intellectual traditions meaningful conditions without replacing them with reductive computational metaphors.

## Output (machine-readable fixture / human report)

For each RF-ID: \`original_expression\`, \`proposed_academic_label\`, \`domain_class\`, \`reference_identity_status\`, \`source_refs[]\`, \`rules_recovered[]\`, \`rules_proposed[]\`, \`non_equivalences[]\`, \`candidate_assays[]\`, \`falsifiers[]\`, \`competent_nulls[]\`, \`historical_standing\`, \`uncertainty[]\` and \`approval_status\`. Initially, unexecuted outputs carry no empirical credit.

At the end: a frozen source/digest manifest, reviewable draft priority order, and a disclosure dossier for any proposed actionable rule changes. No auto-merge.
