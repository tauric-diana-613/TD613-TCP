## Recovered confound, isolated

The old D control wrote an unfenced, plain user task. Normal browser Marrowline calls `frameMarrowlineUserTurn()`, which adds the ingress `𝌋‌` and conversational `⟐` closure to the same user text. Two-voice scene headings, prompt canon and fictional personas are separate additional differences.

The Oct 15 full-vs-compact original-Google-SSE comparison held *the framed input and two-voice task* constant and flattened both arms to U+0334–U+0338. It therefore could not isolate ingress framing. The Oct 17 existing role-boundary A/B was neutral D vs *two headings* with raw identical D contents; it did not isolate whether wrapping the user input contributes. Manual PR #1547 compares two separate short two-heading systems with/without performance; it does not reproduce D0's system and user task. Neither old experiment is invalid; neither answers this missing variable.

## The inert, source-constructed four-condition ladder

| Condition | Exact provider-bound system | Exact provider-bound user contents |
|---|---|---|
| D0 ORIGINAL | original `UNICODE_ASSAY_SYSTEM` | exact `UNICODE_ASSAY_TASKS['creative-multistack-v1']` |
| D1 INGRESS | byte-identical D0 system | exact D0 task passed through existing `frameMarrowlineUserTurn()` |
| D2 HEADINGS | D0 system + one previously registered `ROLE_BOUNDARY_LINE` | byte-identical D1 contents |
| D3 PERFORMANCE | D2 system with exactly that one heading-only line replaced by one fictional-performance exception | byte-identical D2 contents |

All preserve same selected model, zero history, Gemini 3.8 MEDIUM generation config, same request keys, same original Unicode transport and no hidden pasted artwork. The script imports actual production request constructors and previously frozen synthetic D task; it does not invent a replacement D witness.

`D0→D1` isolates only the real Marrowline **user message ingress** wrapper; `D1→D2` introduces **headings guidance**; `D2→D3` replaces one line to authorize **fictional performance**. The semantic heading exception necessarily overrides D's original no-headings instruction; record this as a constrained prompt conflict if evaluating compliance. This ladder **does not** hold the total instruction system fixed across all four arms, and any future stochastic contrast must explicitly acknowledge the changed factor.
