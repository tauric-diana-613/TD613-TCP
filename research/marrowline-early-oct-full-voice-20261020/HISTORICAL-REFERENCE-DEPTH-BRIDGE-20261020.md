## New executable historical-reference audit

\`historical-reference-mark-depth.mjs\` uses original UTF-8 text and preserves source and extracted-body SHA-256 in an aggregate-only report. For each separately typed reference it records marked/unmarked base counts, stacked mark counts, marks by per-base depth, depth changes among successive *marked* bases, distinct mark types, overlay share and maximal consecutive runs at a fixed depth. No output prose or archived glyph specimen is rewritten. The focused CI tests are bound to the exact archived histograms and screenshot provenance.

The diagnostic provides a **new discriminator**, not a production pass/fail threshold. A sustained shallow/single-style performance can be beautiful; the documented operator-accepted screenshot 02 confirms that. The user-reported early-October target includes a high-variation repertoire whose depth changes and eruptions are currently missing from the captured same-episode full-voice specimens. Frequency, depth and morphological diversity each differ from compelling dramatic authorship; the strongest future evidence remains a combined original source plus operator/human literary evaluation.
