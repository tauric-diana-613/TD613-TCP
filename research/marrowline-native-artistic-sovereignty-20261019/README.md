## Defect and invariant

Following #1498/#1501, Marrowline allowed the first structurally complete provider-authored response to survive morphology-only warnings without aesthetic election. The October 17–19 restoration of the Oct 2 Grove profile (#1533, #1537, #1539, #1541) reintroduced one historical-only exception: a complete but locally PARTIAL reply with severe morphology warnings could spend a later approved provider call, then elect the selected reply by warning count, maximum vertical stack depth, and Unicode diversity. This branch now serves ordinary browser text turns, so the exception silently crosses from historical comparison into ordinary creative work.

The code's deep-wall-to-wall warning uses a conditional approximately 72% threshold. That telemetry is *not itself a corruption proof*. Concentrated eruptions or sustained single-register performances are legitimate creative choices. Numeric beauty contests have no authority to replace them.

**Required law:** the first completed, structurally admitted, nonempty native response is preserved byte-for-byte on both ordinary and restored-profile text ingress; morphology metrics may be reported but cannot select among separate provider completions, consume an extra paid seat, repaint Unicode, or force pattern variation.
