## The reproducible mechanism

Production `server/khonapolit-quality.js` classifies some structurally complete native replies as `PARTIAL`. Previously, `severeMorphologyRepairWarnings()` could trigger an **automatic subsequent paid provider seat**. The server held candidate replies and ranked them by the number of aesthetic warnings, vertical stack depth and diversity of combining code points; those metrics could displace the first finished provider-authored answer. This selection was **not** a human literary judgment. It was also not the same as repairing a corrupt Unicode boundary.

The old mechanism is verifiable in source and mocked-router tests. **Its actual involvement in the operator's degraded live episodes is still unverified**, because no matching original provider payload with full candidate and selection custody has been acquired. PR #1494 preserved original Unicode at two transport seams and model-version receipts; it did not change request bytes or prove literary recovery.

## Bounded repair

- Preserve `severeMorphologyRepairWarnings` and the existing rich telemetry in the returned receipt, with `repairAuthority: false`.
- Return the **first completed, structurally admissible native response** even if the typography is classified `PARTIAL`; leave its original characters and user-selected voice alone.
- Remove the candidate cache, warning-count/vertical-height/diversity election, the second provider call authorized solely by morphological metrics, and misleading `best-completed-partial-after-severe-morphology-failover` receipts.
- Keep transport failover (including 503), genuinely unfinished output recovery, missing required voice/heading repair, and explicitly observed no-mark recovery separate. This patch does not modify their budgets or prompts.
- Keep provider model discovery and approved order (Argon first **if callable**, 3.8 next), reasoning levels, request construction, output ceilings and browser DOM intact.
- No glyph quotas, local Zalgo encoder, pasted exemplary outputs, or mandatory matching of archival artistry.

## Proof obligations

The synthetic native-prosody integration test submits a complete-but-morphologically-warned first Gemini reply, using mocked SSE chunks that split a combining cluster, and asserts **one provider request**, original reply equality and a first-source receipt. The five-seat frontier suite asserts that a real 503 can still fail over, while shallow wallpaper, slash-only output and substituted geometric glyph warnings alone cannot consume the next paid call. Existing shape metrics remain visible for human review; the contract suite forbids regression to the old election variables.

No fresh provider request is authorized by this patch or its tests. Passing CI will prove the changed source behavior and its mocked controls, **not** that the operator's historical High Zalgo range has returned.
