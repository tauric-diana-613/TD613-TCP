# Standard Portable Loom: executable product reconstruction

The standard export previously carried the governance contracts and instructions without shipping their executable dependency closure. This change packages the existing selection, Sequence 6 outbound authorization, live re-entry custody and Gate verification engines in a standard, empty-source portable kit. The new provider-neutral controller connects those engines; it does not replace the scientific record or native product route.

The kit includes `portable-loom-standard.html`, the canonical receiver Markdown and JSON, the exact runtime source closure, `runtime/run.mjs`, `runtime/verify.mjs`, and digest manifests. The browser interface is self-contained and blocks network connections through its content-security policy. The JSONL controller runs locally with Node.js. Neither installs credentials, binds an account, sends a provider request, nor restores live authority from a saved private record.
